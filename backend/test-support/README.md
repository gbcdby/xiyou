# 真实数据库检查环境

`postgres.mjs` 为每次检查启动独立的 PostgreSQL 18.6 进程与数据目录，使用随机端口和只监听本机的 TCP 连接。测试环境由固定版本的 `embedded-postgres` 提供；应用数据库访问使用 `pg`，可以连接独立配置的 PostgreSQL。

所有数据和日志位于本仓库的 Agent 临时输出目录；辅助函数返回 `pool`、仅供测试进程使用的连接配置与异步 `stop()`。调用者须在清理阶段关闭连接池和数据库。不得把连接密码写入正式证据。

该辅助环境不证明应用事务、权限或恢复行为；对应结论须由调用真实应用入口的行为与故障检查取得。没有数据库或启动失败时直接失败，不使用内存后端替代真实数据库验收。

实时适配依赖固定为 `socket.io` 4.8.4；同版本 `socket.io-client` 只用于技术检查。传输连接和 ACK 的可用性不构成世界提交、授权恢复或五客户端运行验收。
