## 1. 故事钩子与改编边界

**西去的路被火与热烟挡住，山下居民也盼着风雨。铁扇公主拥有能改变山势的宝扇，却不愿把宝物交给一句“用完就还”。玩家需要弄清她真正担心什么，验证借来的物件，帮助大家完成现场准备，并让借用有一个看得见的交代。**

原著第59–61回提供旧怨、假扇、变相骗取与反骗、真扇息火生风降雨、最终归还等情境。[S1–S3] 本章不用武力夺扇、钻腹要挟、围攻或伤害来解决拒绝；不把原著的连续扇动次数做成重复点击任务。

紧凑连通山路、可安全复查的验扇台、分区导流、明确借用范围与和平暂缓是原创改编。三借表现为首次求借/试用、带着实际证据修订借用、通行后的续借或归还谈判；若第一次已诚实借得真扇且实际履约，就直接完成，不为了章名强制被骗三次。

本章不预设所有世界火患永久消失。完成三处操作表示本次指定西路与已声明照管范围安全；若没有消除其他火根的实际规则与事件，不在结语写“火焰山永不再燃”。已提交的冷却和开路不因后来争执/归还扇子回滚。

本文“属铁扇”指其作为私物出借人的同意与归还权，不另建第二个物件 `owner`。游戏内当前物件保管者/容器/落地点仍只有一处，实际交接按#27更新；出借人的有限使用许可和归还义务通过已有私物处理同意及来源承诺保存。放在操作台也不变成可公共领回的工具。

## 5. 借用、验扇与反骗

### 5.1 每次借用的真实边界

提议必须明确实际物件、借用人、允许操作人、用途/区域、归还地点、是否可转交、到何种事件为止有效。铁扇接受只形成许可/承诺；仍需她或已有明确处分权的保管人实际交出该柄扇。玩家不能用“你已经答应”跳过交接。

首次可以请求限定试用，铁扇也可以直接同意已说明的完整用途。她可给真扇、以假扇掩饰、要求先完成具体现场准备、提出自己到场施用，或拒绝此次借用；上述意图均须落到她实际持有的对象和许可上，不允许模型现场造第三柄扇。

允许的可执行条件包括：先把挡板锁好、明确归还收件人、按实际用途缩小许可、安排当地人共同保管。不得把未经当事人同意的婚姻、人格改变或红孩儿不存在的归来作为硬通关条件。她仍可坚持不借，玩家可暂缓并完成安置结果；不会由故障降级替她同意。

“铁扇亲自施用”是有效替代，不把私物强转给玩家：她本人自愿到操作点，玩家完成同样准备并合法递交山况。若选择该路线，归还项记为“始终由本人保管，无借出”，不伪造玩家借还；验扇和开路仍不能省略。

### 5.2 受控验扇

1. 两位玩家把限位架在验扇台就位并锁定，盖住试火盆外溢方向；锁定之后无须继续扶架。空手或未借到扇仍可完成准备。
2. 在已获准用途内，持有者/铁扇把眼前那柄扇放到台位；玩家检查盆、风向带、冷凝石均为本次复位状态，预览已知判据。
3. 执行一次限定试用：真扇使盆内火势降低并在冷凝石上出现对应水迹；假扇使热流带向上且没有该水迹，盆盖把影响限制在台内。两种效果来自固定内容规则，不以NPC赞叹、工具名称或单一花纹判真。
4. 当场见到的人得到试验观察；要让唐僧/悟空/铁扇知道，另行展示记录或邀请复验。试验仅证明**实际试过的同一物件**及其当时状态，不把证书复制给另一柄同名扇。

所有拿取/放置/交接保持物件唯一性；缩小、展开、外观变化不改变实物身份。物件换手不抹除已有试验来源，但接收者须合法取得物件关联；看起来一样不能沿用证据。未验扇只允许在台内试用，不能直接向山路热区操作。错放、试验取消或掉线不损毁扇，复位盆后可再验。

### 5.3 换扇、改约与冒名收取

验出假扇后可以带回实际试验材料，请求真扇或请铁扇亲自到场；假扇按其借用范围归还/保管，不把它凭对白改成真扇。已经完成的山况调查、挡板和水沟准备保留，不重开关卡。

牛魔王可在实际获知归还安排后，提出“由我代收”，或在已声明布局内借用在场熟人的外貌。若八戒不在真实名单，绝不生成“假八戒”或八戒已转告的陈述。不得伪造玩家私密授权；造型/姓名吻合不是收件许可，配偶关系也不是铁扇的同意。

玩家可去当面核对铁扇当前授权、把带来源的收件范围送回持有人，再走向指定交接点；唐僧可以劝先保管、悟空可以提出核查路线。未经核对的候选收件人不能触发合法归还。若持有者已经在仍有效范围内把物件给了某人，按真实保管关系记录，不能由剧情把物件自动收回；本章不提供无授权的私物处分动作，因此冒领提议不形成玩家一误点就永久丢扇的软锁。拒绝或撤离的牛魔王不会触发战斗。

## 6. 三项环境操作：条件不同，结果可见

三项依次解除西路阻碍，材料准备可以并行。试用和生产操作共用已验证物件身份，但用途范围分别重验。使用说明由铁扇在授权时提供的固定操作示范/公开山况记录给出，不猜一句咒语，不由模型临时编操作口诀。

| 关口 | 玩家准备与可推理条件 | 有效操作与权威结果 | 试错与幂等 |
| --- | --- | --- | --- |
| P1 谷口压焰 | 读风向带；把挡板放在村路一侧而非排出口，两真人两端确认锁定；操作台无人遮挡 | 获准操作者在锚点对谷口使用已验真扇，提交明焰熄灭，露出到烟峡侧道的可走石阶 | 挡板朝向错误时提示缺项、无消耗；同一关口已完成则不重复计进度，不让反复扇动涨分 |
| P2 烟峡导风 | 到上下风口观察；将导风叶片连接到无人岩隙排烟出口并锁定；检查侧道开口真实畅通 | 在P1已完成时使用生风操作，热烟沿已布置通路退去，峡道可见/可达范围实际改变 | 接到居民一侧或出口未开则拒绝；重新调整保留P1结果，不重新起火惩罚 |
| P3 余烬坡引雨 | 实地比较坡势，分别疏通两条入槽浅沟，放置雨标；本人把扇送到该操作锚点 | 在P2已完成、分流成立时使用降雨操作，集水槽与两沟出现水、土温观察变为可通行，开放西岭出口 | 只放雨标/只说清沟不成立；已完成一沟保留；重复操作无额外天气/用量复制 |

`RoadOpen` 必须由P1、P2、P3的实际效果和出口路径共同成立；不能只有天气动画或三次点击计数。角色的操作位置、风口/挡板版本、物件与借用同意、当时人数在提交时重验。P3后再次归还扇子不会撤销已经发生的降雨和道路状态。

无需真人永久控制风口。可锁定的机关使两人先后完成所有准备；五人可同时准备P2、P3并处理验扇/协商。悟空可以参与授权扇动，但不自动完成玩家的挡板、导流、水沟工作。若铁扇授权的实际操作者是玩家，玩家经同一有限动作执行；不会为了等NPC一句施法台词阻塞已完成准备的房间。

## 7. 履约、拒绝与恢复

| 事件/状态 | 合法处理 |
| --- | --- |
| 借约已答应但未交扇 | 继续等候实际交接或重约；背包和现场不生成扇 |
| 正在准备时铁扇提出收回/撤回未执行许可 | 未提交的相关用扇计划失效；持有人按当前归还安排实际送还或再议，已有环境效果保留 |
| 已用扇、归还地点不可达 | 可选择已声明的东侧回路，或请求铁扇本人改到归还驿亭；改约须本人明确同意，不瞬移物件 |
| 合作未提交时有人掉线 | 旧就位失效，安全准备保留，重新就位；已锁定挡板/架体不倒退 |
| 扇由掉线玩家持有 | 扇是私物借用，不在公共强领集合；借用开始时可由铁扇、借用人共同选定一个已在场的NPC保管者，真人只取得限定操作授权；若确由真人持有，先等其重连或按共用未完成结束，不擅自扩权夺物 |
| 公共木楔/工具由离线者持有 | 仅对预先声明清单按#27近距/宽限/控制版本领回，不扩大到扇和私信 |
| 超时或连续两次无有效回应 | 显示暂缓，受控策略可走已有许可的等待/归还路线；不能新增借出、续借、原谅或代收许可 |

正常借用优先采用“可信NPC保管、真人有范围限定的操作授权”，两人/五人都可完成合作，不把私人扇子的可解性依赖某一玩家持续在线。玩家使用前，保管者须在实际操作点依已有许可把同一柄扇放入限位台，成为明确的唯一保管位置；玩家只能近距操作这台中、已获授权的实物，不能远程动用NPC背包。也可由NPC本人按已接受计划到点施用。没有准备好物件时仍须等待实际导航/放置；模型故障只可执行先前已许可的安全步骤，不能发新借约。玩家选择自己持有时须在交接前明确提示该恢复范围；这不授权系统代做私物交接。不得把未归还物件在结算时从库存删除以凑履约。

**实际归还**要求同一柄已借出的扇、当前有效的收件授权、双方真实在场与一次转交；铁扇的收讫记录在真实交接后产生。若她本人始终保管，只需核对没有借出债务和其实际去向。

**合法续借**要求铁扇与原借用人明确接受新范围：继续在当地照管余烬、唯一保管人、可用地点、归还触发条件与地点。若由本地守望人保管，还需守望人本人接受，并实际把扇交给他。旧借约的义务如何延后须明确；续借不标“已归还”，后续若无实际归还事件就一直保留未履归还事项。本章不靠现实时间等待来逼玩家续借，也不自动在 Session 结束后模拟归还。
