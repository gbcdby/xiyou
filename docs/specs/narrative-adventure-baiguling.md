## 1. 故事钩子与改编边界

**一位姑娘提着食盒上山，说要请饥饿的取经人歇一歇。她离开后，寻女的老妇和寻家人的老翁又先后出现。每次说法都更像一桩误会，山路却越来越不适合停留。玩家既要保护取经人，也要让真正看到的事情进入师徒的判断。**

原著第27回有女子、老妇、老翁三次化身以及悟空与唐僧的信任冲突。[S1] 本章把“三打”改为三次识破诱导/安全脱困，不提供攻击、杀人、尸体搜刮和念咒惩罚。已被玩家证明的事实不因下一幕需要争吵而抹掉；成功建立信任时不强制逐走悟空。

三处紧凑山路、当地帮工、食盒查验、护栏和离岭方案是原创玩法。玩家可先提出保护性措施，未证明对方是妖精也能拒绝陌生带路；不能把“看着可疑”直接升格为身份判定。

## 2. 所有变体共用的事实

| ID | 权威事实 | 合法获知范围 |
| --- | --- | --- |
| BG-F01 | 三次外貌均来自同一白骨精，她想把唐僧带离公开山路 | 她知道自己的目标；别人需亲见变相或取得有来源的连续观察才能建立身份关联 |
| BG-F02 | 初次食盒内有遮盖的石粉/枯叶假饭，旁边茶棚有真实清洁食水可取 | 食盒所有者知道内容；玩家获准当面打开或见其落下后检查才形成证据；不因远距点击知道 |
| BG-F03 | 所称田间家人、老妇寻女、老翁寻妻女的指路均指向同一条封闭岔路；当地真实可通路线在高处 | 护路记录和现场路况可核验；“那条路不通”不单独证明三个人同一真身 |
| BG-F04 | 三处诱导都没有不可逆伤害；最差合法误入为到达可返回的偏路等候点 | 路线错误带来回撤/重组，不生成死亡、强制拘禁或战斗 |
| BG-F05 | 山道护栏松动但可用两端木楔固定；支架、引路牌和真实食水均在可达公共点 | 必需资源不在白骨精私物或离线玩家私密区里 |
| BG-F06 | 唐僧愿保护看起来需要帮助的人，也愿避免让同伴孤身进险地；悟空愿保护师父、愿提出查验 | 各自计划随合法证据变化；不是永远信/永远不信的脚本开关 |

机关和真假食物规则在内容版本中固定；LLM 不临场造毒药、替换真身或把安全地标改成悬崖。外观变化不改变角色实体、物权和已经获知的关联。无法连续观察到新化身的角色可以怀疑，但任务板只标其实际证据，不公开全知身份。

## 3. 地图与可操作对象

| 空间 | 对象/操作 | 探索价值 |
| --- | --- | --- |
| 山口茶棚 | 真实食水、护路记录、可休息位置、公共木楔 | 先准备安全歇脚，核对“附近有人家”的说法 |
| 送饭石坪 | 食盒、碗盖、姑娘、可看见侧坡的观察点 | 在当事人许可下当面看食物；观察其离开路线，比较来路 |
| 回声岔口 | 老妇、两块移位指路牌、旧路封绳、护路人 | 还原实际路向，向唐僧说明可查和不可查的事 |
| 脊上窄道 | 老翁、松动护栏、两端锁点、观望亭 | 两人锁定护栏、引导队伍经过；远侧观察可看见退去者的实际变化 |
| 西岭出口/山口退回点 | 到达标记、队伍行李与公共物回收架 | 形成继续西行、折返安全处或未完成的不同实况 |

主路是一条有短侧环路的连续山径；每个诱导点都有返回公开道路的路线，不能靠切换区域按钮完成。墙、岩石和竹丛影响视觉/听闻，现场说过的话只进入当时受众。

| --- | --- | --- |

| B 山路向导 | 知道旧路与现行近路 | 核验来路、纠正指牌、引导实际同行 |

| D 采药人 | 熟悉本地植物与石坪 | 检查食盒/枯叶、追踪合法痕迹、观察变相 |

| 人数 | 职责组合 |
| --- | --- |
| 2 | A+D+E；B+C |
| 3 | A+D；B；C+E |

每人一个角色；职责只提供起始便利，公共知识可再取、工具可合法交接。持续并行工作为**核实陌生人的说法与来源**、**准备真实食水和安全通路**；三次接触之后仍有送达、护送、锁定/收尾和公开解释。两人不需要第三人扶栏，锁定后两位均可离开。

## 5. 三次接触：有干预结果的进程

| 阶段 | 白骨精的可用意图 | 玩家可做的现场工作 | 完成与下一阶段 |
| --- | --- | --- | --- |
| 一：送饭 | 以女子外貌请唐僧到偏路用饭；可允许看盒、岔开话题或退走 | 把真食水送来；当面请求开盒；一人维持公开歇脚、一人沿合法侧路观察离去 | 食盒矛盾被合法发现可阻止诱导；即使她不让看，也可选公开休息。她实际离开后才开放老妇接触 |
| 二：寻女 | 以老妇外貌要求陪她去旧路找人，或指责队伍没有帮忙 | 查护路记录/封绳，比较她所指方向；请当事人在公开点等候并请护路人核验 | 旧路查验完成后可明确拒绝盲目带路；已经知道第一骗局的NPC保留该知识。老妇实际退走后开放老翁接触 |
| 三：寻妻女 | 以老翁外貌提出最后一次带路或离间，不能强制师徒反目 | 固定高处护栏，汇齐两次现场材料；保持队伍公开相互可见；从合法观望点跟踪其退去 | 若玩家亲见同一对象变回/变相，获得身份关联并可分享；否则只确认三次诱导不可信，仍可安全越岭 |

三次外貌变化有真实时间、位置和受众。阶段触发条件是上一化身已离开接触区、队伍推进到下一节点及有效场景时间可推进；不是固定倒计时强行换幕。已识破者不会忘记，白骨精可以改向尚未知情者说话；必须依实际听闻选择目标，不能读取秘密名单。

本稿保留完整三次接触的默认游玩路径，但不为了演完而拦住玩家。队伍提前准备好高路并明确拒绝继续接触时，可以直接护送越岭；复盘只写实际经历的次数，不补演“第三次”。当玩家提前连续跟踪并看见变相，早识破合法成立，后续以防止陌生人绕到未获知者、保持通路和送达证据继续推进；不把聪明行为判为破坏剧情。

### 5.1 把证据变成师徒行动

`FoodMismatch` 仅说明眼前食盒与“饭食”的说法不符；`RouteMismatch` 仅说明具体指路与现场不符；`IdentityLinked` 需要真实的连续观察/亲见变相或合法收到同等证据。把三者分开保存。

先将食盒证据送给唐僧，他可决定在茶棚核查，开放公开食水安排；先把旧路封闭证据给悟空，他可提议改走高路，玩家先准备护栏再回接师父。队聊说“她是白骨精”不会把任一证据送到 NPC。唐僧可以仍想帮助寻亲者，但只能走双方实际同意的公开查验安排，不能剧情强制独自进入偏路。

没有隐藏“相信悟空达到80”之类胜利值。已经合法送达的证据必须能影响可用计划和可解释理由；AI可质疑来源、要求同地核验，不可无期限否定确定的路况。即时对白不生成 `IdentityLinked`。

## 6. 有限动作、拒绝与补救

| 动作 | 前提 | 实际效果及失败行为 |
| --- | --- | --- |
| 检查食盒 | 在场、眼前对象许可打开，或其已放置并允许检查；物件版本有效 | 生成具体内容观察；拒绝开盒只记拒绝，可去茶棚，不直接识破 |
| 对照指路 | 取得护路记录，实际到达对应标记/封绳 | 生成路况证据；只转述则是有来源陈述，不自动授予亲历 |
| 封存/分享观察 | 仅对自己合法观察及允许转达的来源 | 接收者获得相应范围；晚到不补听，跨墙不分享，未知真身不泄漏 |
| 固定护栏 | 木楔到位、两人两端就位、锚点可达 | 一次锁定并开放高路；中断保留安全准备，不消耗工具、不自动倒塌 |
| 提议公开查验/随行 | 目标本人及真实目的地/引路者明确 | 同意后按实际移动；撤回暂停，父子/师徒身份不替他人作同意 |
| 回撤 | 角色身在可返偏路，返回路线可达 | 走回公开点并重新安排；不强制悟空单人自动救出所有人 |
| 申请出岭 | 路况合法、当事人获知安排并决定出行、公共物妥善收尾 | 实际到出口后才结算；口头“识破”不能跨过空间条件 |

白骨精对请求可拒绝/拖延/退去；玩家始终有真实食水、公开验证和高路替代，不以她认罪为成功门槛。她的掩饰失败不触发攻击。全局无饥饿掉血或限时死亡。误信带路的后果是要核验回路、重新团聚，不是一次错误永久死锁。

唐僧或悟空两次无有效决策/模型故障时，可按已知证据执行现有安全计划的普通移动；不能代作原谅或决裂。公共工具领回遵守主 Spec；食盒、个人信件等不成为公共强领物。少于两人时不推进下一次诱导/风险，已锁定护栏和已知证据保留。

## 7. 结局和实际去向

| 结局 | 必须成立 | 不得误报 |
| --- | --- | --- |
| BG-E01 识破同行 | 至少一条有效真身关联已合法送达唐僧/悟空；安全高路开放、公共物收尾；双方明确继续同行；取经队伍实际到西岭出口 | 只凭拒绝/背原著认证；必然赶走悟空；只播放白骨精消失字幕 |
| BG-E02 未尽真相、平安越岭 | 已确认食物/路况的至少一条风险证据；公开安全路线可用；师徒接受保护性安排并实际越岭 | 对无权知道者透露真身；把未知写成认罪或完全和解 |
| BG-E03 暂避回山口 | 本人选择暂不继续或师徒尚未达成同行；已在偏路者实际返回、公共物妥善保管；相关人物到茶棚/独立等待点 | 宣称已经取经越岭；将暂缓写成永久逐走；抹除之前救援 |
| BG-E04 未完成 | 按共用规则主动/技术结束 | 保存具体位置、证据和未尽操作，不补任何到达/身份知识 |

白骨精实际在山后退出区或独立等待区，不能靠其死亡完成；她没有认罪也可结束安全路线。队伍没有完整身份链时可选E02，不要求折返刷一次变身目击。E03之后连续游历只按真实同伴状态进入下一章。

## 8. 章内验收

全部 **NOT_RUN**；继承主 Spec 的共用空间、人数、权限、AI、恢复和体验义务。

| ID | 输入/检查 | 结果与失败判据 |
| --- | --- | --- |
| BG-AC-01 三次与固定事实 | 三种外貌、早识破、提前走高路、不同种子 | 同一真身与既定物/路况；接触次数如实；不强制失忆、补演或伤害 |

| BG-AC-04 自主与补救 | 开盒拒绝、误信带路、唐僧要求帮助、悟空急躁、模型故障 | 仍有公开核验/回撤/高路；已取信不强制决裂；无攻击代解 |
| BG-AC-05 顺序与非阻塞 | 先食盒后路况、反向顺序，三AI并发队列 | 休息/改路计划可见改变；普通行走不中断，白骨精无全知感知 |
| BG-AC-06 结局 | E01–E04、撤回随行、缺席八戒/沙僧 | 逐项真实到达、知识和名单；未知不写全知，拒绝不写假身 |
