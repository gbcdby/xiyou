## 1. 故事情境与改编

**来客误饮了子母河水，在迎阳驿求助。取水之路、当地礼节和一场真诚的挽留同时摆在队伍面前。玩家要先让需要照顾的人得到帮助，再把各方真正愿意的安排落实成可见行动。**

原著第53回有子母河、解阳山落胎泉及取水解困；第54回有迎阳驿、女王迎亲与通关离境。[S1–S2] 本章保留这些辨识点，去除战斗取水、假意成婚作为唯一路线和第55回蝎子精延伸。

魔法身体现象只作为故事规则：以“误饮后的不适/需解除状态”呈现，不做身体羞辱、逼迫生育、疼痛计时或医学模拟。是否请求解除由受影响本人明确决定，玩家不能替其喝水或替其同意。唐僧开局明确希望解除后继续考虑行程，但可以拒绝某次未经核验的递水。取水安全协作、公用紧急份额、公开澄清和暂留结局为原创改编。

## 5. 协作解困的有限规则

| 操作 | 前提 | 提交效果 / 拒绝与恢复 |
| --- | --- | --- |
| 登记急用请求 | 受影响本人明确请求、真实状态存在、授权接收范围明确 | 形成本次有限取水资格；玩家替答/不存在的缺席角色拒绝 |
| 申请额外/直接取水 | 在场、用途/容器说明可送达井主 | 井主可拒绝或提出公开安全条件；急用额度另按已公开规则办理，不能伪造其同意 |
| 复位汲水架 | 公用绳桶/支撑到位，两真人位于不同锁点 | 一次锁定；取消/断线不消耗关键物，不需第三人撑杆 |
| 核验水源/取水 | 架已锁定、来源确为落胎泉、合格清洁容器、剩余已授权份额 | 生成带本次来源和份数的泉水物件；普通水仍是普通水 |
| 送交与使用 | 当事人实际在场、本人同意此份已核验水、容器/来源有效 | 实际消耗一份并解除该人的对应状态；承诺“已喝”或代理点击不生效 |
| 核对恢复 | 解除事件已提交、当事人合法感知并确认可继续安排 | 开放正常行程；不把没喝者一并治好，不追加随机失败率 |
| 收尾 | 借出器具实际归还，剩余水按授权保管/退回，登记相符 | 完成公共工作；亲身状态不因未归桶回滚，但圆满收束仍须收尾 |

每名实际请求者需要一份，不设隐藏剂量换算。关键水误放/途中取消不消失；被污染或确实洒失按固定规则标无效，凭失效物件和原登记可在泉亭补领对应份额，不复制有效水。没有永久耗尽的唯一救命水，也不能无限囤积有效份额。

以两人为例：一人先在驿站取得请求及文书，另一人拿取支撑和核对泉源；两人会合复位后分工取水/回送，支架保持锁定。五人时照护、取水、架体、文书、会面各有连续工作，不能让三人等双人取水完成才开始全章。

## 6. 诚实会面、去留与承诺

### 6.1 信息送达与误传

公开欢迎可以被一些场景人物理解成迎亲，但世界并没有自动生效的婚约。礼仪院的待办文书必须分别显示“提议”“待本人回应”“已明确决定”和“已履行”，不得把婚礼布置本身当同意。

若玩家先取得唐僧取经说明并获准公开，女官可先把接待改为送行/交流，女王收到后选择如何邀请；若先布置欢迎，再收到唐僧明确不同意婚事，需要实地更正告示、收回未生效礼单并向实际收到旧通知者澄清。已经听到旧说法的人保留其历史视角，通过新消息修正；不删除旧事件伪装从无误会。

来客不愿公开感情细节时，只允许披露完成通关所需的最小决定，如“未成立婚约，按访客办理”；不把私人谈话全文放队伍板。对话期间其他玩家仍能归还器具、整理本人许可的行李、准备出口和更正已授权文书。

### 6.2 当事人选择与合法后续

| 当事人状态 | 玩家可安排 | 禁止代替 |
| --- | --- | --- |
| 双方愿意会面 | 提供两个公开地点、送达时间/范围、实际带路 | 不得把会面同意当成婚姻或暂留同意 |
| 一方拒绝当前会面 | 重新提议地点、书面传递已授权内容、直接走通关手续 | 不封锁照护/出口逼迫其接受 |
| 唐僧决定继续取经 | 依法验引、明确没有假婚约、收拾行李/道别 | 玩家不能替他承诺以后回来成亲；女王不必原谅或说祝福 |
| 唐僧自愿暂留 | 登记明确期限/条件的客居安排；悟空独立决定自己的等候/去向 | 不将暂留写为已经成婚/放弃使命；悟空不被强制同意 |
| 双方谈及亲密/婚事 | 只记录本人真实表达及各自范围；涉及实际关系变更须双明确决定 | 送礼、沉默、NPC超时与玩家选择不算双方签字；本章不制作强制婚礼结局 |

暂留使用有效场景时间之外的明确叙事约定，例如“在客居院休整后再议”，不要求现实等待若干天。它是可完成的本章结果，连续去下一章前仍需真实恢复行程事件。温柔道别、保留遗憾或尚未理解均可与合法离境并存。

## 7. NPC 自主与补救

女王可以拒绝某地点、要求直接听唐僧说明、表达不满或不接受私人邀请；仍不把通关/水源作为交换爱情的筹码。唐僧可以请求休息、延后会面、拒绝未经证实的水或选择暂留。悟空可以提议取水/先准备出口，不能偷偷替师父订亲，也不能以“骗一下就好”强行覆盖诚实路线。

如意真仙对额外用水与私物有实质拒绝权；本章公共急用规则是明确的既有场景制度，不是玩家说服失败后突然出现的无限后门。拒绝急用受理必须指出缺请求/未锁架/来源未核验等具体项；满足既定手续即可执行，不追加好感门槛。该改编须在开场女官介绍和泉亭告示中可发现。

模型故障时场景登记、合法出具公开文书和已同意安排的普通移动可降级，女王/唐僧的感情与去留决定不得代做。连续两次无有效回应显示“暂缓”，允许补材料、换方式或真实未完成结束。掉线不清除已解除状态和已锁架，旧同意不能完成新目的地安置；本人撤回递水许可时未执行用水保持可再交接。

## 8. 结局与实际离场

| 结局 | 必须成立的事实 | 实际去向与复盘 |
| --- | --- | --- |
| NE-E01 诚实道别、继续西行 | 本局请求解困者实际获得对应解除；器具与份额收尾；无虚假已生效婚约；通关材料实际交付；唐僧明确离境、悟空知情同行 | 唐僧/悟空及实际在队者走过城门出发点；女王可在外苑道别或留宫，不强迫祝福 |
| NE-E02 暂留相待 | 解困与公用物收尾完成；唐僧明确暂留且客居方同意；女王获知准确范围；悟空有自己的有效去向 | 唐僧实际到客居院并确认安置，悟空到约定等候点/独立去向；未成婚、不宣称已过关西行 |
| NE-E03 解困后暂缓会面 | 解困和收尾完成，双方尚不愿会面/决定去留；团队明确选择以访客暂居收束，主人及当事人同意 | 相关角色真实到迎阳驿安置；保留未决感情与行程，不写拒婚/出境 |
| NE-E04 未完成 | 共用结束条件成立 | 实际未解除者、未归物、未递交材料均保留；不强行安置/补同意 |

离境权不等于离境事实：通关文书齐全仍需本人决定并走到出口。NE-E02/03的真实离场是从故事会面地点走到已同意的客居/驿站，不能播放出城镜头冒充继续取经。后续连续模式由真实行程恢复事件决定，不能下章自动把暂留改成西行。
