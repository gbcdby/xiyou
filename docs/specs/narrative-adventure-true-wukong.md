# ADV-001 CH05：灵山路·真假美猴王

## 0. 状态与设计结论

- 归属：[ADV-001](narrative-adventure.md) 与 [后续章节/前情契约](narrative-adventure-continuity.md)，修订 `CH-Design-1`；任务 [#30](https://github.com/gbcdby/xiyou/issues/30)。基线 `60e68a83cac2bd5d45b410a64545730a2a1c3eb4`，2026-11-12。
- **保留条件候选，提交独立审查**：本稿以可观察的来源连续链和真实行囊救回提供具体机制，尚不能称选题门槛“实测通过”。不启动红孩儿替补，不改变六章位置。
- 全部模型、源码、运行、真实AI、真人趣味和视觉检查 **NOT_RUN**。本章制作受 A3/A4 以及本章设计审查门槛约束。
- 共用身份投影、按发生时刻授权、合作、移动、同意与恢复沿用主 Spec 和 [#27](https://github.com/gbcdby/xiyou/issues/27)；本章不增设“问模型谁是真的”或“输入暗号验真”接口。

## 1. 保留的故事与明确改编

**两位模样、声音一样的悟空都说要护送唐僧。驿站的行囊却被换了位置，去路上也多出一份相互冲突的取经安排。玩家需要先把人和真实行囊安顿好，再弄清眼前的每个人从哪里来、自己究竟看到了什么。**

原著第57–58回有冒名者夺走行李、真假相貌声音难分、多处查验及六耳猕猴的揭示。[S1–S2] 本章保留固定的真悟空与六耳猕猴，不把“真假”改成两位都真或临时抽签。去除打伤唐僧、对打和击杀；不强制此前已和好的师徒再决裂。

玩家可走的紧凑驿路、开场目送、连续见证、行囊保管与两条出口为原创改编。悟空不是靠记忆题、善良分数、谁更听话或谁愿配合来认证；六耳可听到谈话并仿说，无法改变已经发生的空间与交接事件。最终不安排一位权威到场自动指出真身，玩家须取得足够来源并实际完成保管/离场。

## 2. 固定事实与开场来源

| ID | 固定事实 | 初始知情边界 |
| --- | --- | --- |
| WK-F01 | 跨章核心的真实悟空始终为同一实体；另一个是六耳猕猴，世界真相不随种子或对白变化 | 真悟空知道自己经历；六耳知道自己的冒名；普通玩家不获内部真ID |
| WK-F02 | 唐僧与真实悟空共同来到驿路，在玩家可参与的前奏中约定悟空去取水、查看出路 | 现场亲见者获得正常的悟空关系；晚到者须听当事人合法介绍/接收观察，不能自动补看 |
| WK-F03 | 六耳在前奏的悟空出发后才从山后接近，仿其外貌，试图把行囊引向旧棚，并提出另一路同行 | 无人看到的变相不广播；其企图与真身不在队伍任务板公开 |
| WK-F04 | 真实行囊封口、修补处与唐僧当场交存清单一致；另有一个外形近似的空包和冒名者留下的行程纸 | 唐僧知道自己交存/授权的范围；玩家须比较实物；行程纸是陈述/物件，不能自己改变授权 |
| WK-F05 | 两条人行通道在关键段可由固定观察点完整覆盖，真实悟空与山后来客有不同的实际来源轨迹 | 场景资格和视线由规则记录；遮挡存在的片段不能伪装为连续目击 |
| WK-F06 | 真实悟空与六耳可以拒绝提议或撤离；拒绝、发怒、沉默均不证明真伪 | 事实核验不读取“态度像不像”；安全保管不以任何候选同意认罪为条件 |

**起点不是后台真ID。** 独立章的前奏实际展示唐僧与其长期同行的悟空一起到站、相互介绍、交存行囊和取水安排；连续章仅使用上一章合法延续的悟空关系，并在本章让可见者亲自目送。玩家看到的是已获授权的熟人及其出发过程。若某角色没有参加前奏，必须取得这个过程的合法来源；“系统指定东边是真的”不是证据。

前奏不自动令所有人知情。至少两名在线真人才开始可操作前奏；留在场内的人可选择随悟空走，另一人做行囊工作。若玩家从起点一直合法跟随、未被遮挡且见到第二位到来，则可直接保留此人的身份关联，不强行失忆制造谜题。其同伴和唐僧仍须通过合法分享获知；直接护送也不替代行囊核验和取回。

关卡的镜像布局、入场次序、衣物表现和站位可在开局前固定为有限变体；真假实体不改，所有证据随真实轨迹生成。不能把“左边/先来的/更生气的”固定为答案，也不能凭原著“六耳是假”直接定位眼前引用。

## 5. 来源连续链：可检查的规则

### 5.1 片段与交接

来源链是若干**确实发生的授权观察**之间的内容判据：起点是 WK-F02 的熟人出发；中间为角色实际看见同一对象在一个未中断视域内移动；末端绑定当前候选的合法观察者引用。片段保留发生范围、时刻、遮挡/变身情况、来源者和允许分享的内容。

见证转交必须在两观察范围有实际重叠、前者仍看得到目标、后者已经看见同一目标的条件下，通过一次新的受控分享提交；服务端检查当时空间/关系，不能信客户端报“我看到了”。接收者得到自己的引用，不复制别人的 ref。**片段里出现同样面貌/名字不构成两个片段相接。**

本章有两条合法链：玩家持续随行链；以及驿前院→回廊守候人→桥头守路人→会验亭的已记录见证链。场景见证人只可出具其真实授权观察中已有的片段，LLM 自由叙述另存 CLAIM，不凭说辞生成链。守候人不知道全局真假，只能说明自己从前一位见证人明确指认的对象处接续目击到哪里。

每个发布变体必须提供至少一条完整的场景备用链：前奏目送到回廊的重叠、回廊到桥头、桥头到会验亭逐段有真实可见交接。其存在是已定义的开场事实，不靠实时 NPC 恰好抽到巡视；记录尚未合法交给玩家不等于玩家已知。实际制作须用空间回放检查这些片段，发现虚构视域即拒绝该变体。

### 5.2 断链与补查

遮挡、掉线、目标离开视域、同时出现同貌对象但无法保持对象连续性、相关外观变化或交接过期，都会让该段变为 `unknown`。界面给出“最后确认在水亭、之后未观察到”，不指责某候选。重连不凭旧 ref 恢复断链期间的身份。

补查必须取得覆盖**当时缺口**的另一名合法见证者的已有片段，并现场核对其观察锚点与当时遮挡记录。打开今天的竹帘、让候选重走一遍、重放无权看到的服务器录像，都不能证明过去。若该路径没有这样的片段，只能维持未知；可转到未断的场景备用链，或保护行囊后安全暂缓。

场景备用链的片段固定可请求，不因模型一次不合作消失。遇到记录者模型故障，受控场景流程仅出具其已授权的真实片段；不得代替真悟空同意同行。观察 chain 到达当前候选时形成“此对象接续了开场悟空”的有来源核验，身份揭示只分享给实际接收者。其他观察者仍须各自获得合法关联。

## 6. 行囊调查与有限动作

| 操作 | 有限前提 | 成功效果 / 失败与补救 |
| --- | --- | --- |
| 出具/封存目击 | 来源者确有授权观察，片段未被断链条件否定，接收者在合法分享范围 | 保存带来源的证据；无观察只得 CLAIM/unknown，不授予身份知识 |
| 校核链段 | 玩家到达观察锚点，已获该片段，可核对当时障碍版本 | 标明可接续/缺口；现场当前开帘不重写历史 |
| 对照行囊 | 唐僧允许展示交存清单；玩家走近包、检查封口和修补处 | 认出物件与授权范围；空包不成真包；持包者身份仍另查 |
| 修复扶栏/铺滑板 | 公共工具在场，两端就位、相应锚点有效 | 一次锁定、形成可搬运通路；取消不吞工具，掉线后可重新就位 |
| 中立撤运 | 真实行囊已核对、唐僧授权本地保管、通路可用、两玩家就位 | 真包实际移至公共中立柜，原授权保管关系可追溯；候选不能口头领走 |
| 定向交接 | 唐僧已合法收到完整身份链，并明确授权此真实对象；真包核对完成、双方到场 | 真包唯一转交；引用过期/候选移位需重验，不可按同名替换收件人 |
| 联合会验 | 已取得的片段和实物都送到会验亭/获准渠道 | 规则报告哪一链成立、哪一项未知；不是模型投票，也不必等额外权威 |
| 整理去向 | 当事人决定明确，私物交还/合法保管，路线可达 | 普通移动到实际去向；受控策略只跟随已经确认的安排 |

真包的归属始终是唐僧或其明确授权保管人；六耳挪包的历史是未授权占有/搬移，不使其取得处分权。真假扮相、持有真包或唐僧的一句生气话都不改变真实物权。

### 6.1 两种信息到达顺序的合法动作差异

| 顺序与当时知识 | 此时可做 | 此时不可做 | 后续因果 |
| --- | --- | --- | --- |
| **顺序A：来源链先到唐僧，行囊实物尚未核对** | 唐僧可知情邀请已核验的悟空同行巡包；该对象可获限定的取包准备授权，跟随玩家去旧棚 | 无实物核对仍不能确认取回/归还，空包不能算完成 | 玩家与真悟空走定向回收路线，核验真包后可在棚口直接交回指定人，避免中立搬运 |
| **顺序B：行囊证据先到，来源链仍缺桥段** | 唐僧可授权当地角色中立撤运；两人修桥、用滑板把包带回柜中，保全物件 | 任一同貌候选都不能凭“我是悟空”获得定向交接；也不得把拒绝配合者判假 | 行囊先安全后继续补桥段，成立后在柜前重新取得本人授权并交接；若仍未知可选择安全暂缓 |

差异是授权对象、搬运路线、协作操作和可提交的物件效果；并非同一脚本换对白。顺序A的早期身份信息不是本局通关：还需实物核对/回收/去向。顺序B的早期真包也不是身份证明：还需来源链或明确保留未知结局。

## 7. NPC 自主、拒绝与公平边界

唐僧、真悟空为完整核心 AI，六耳为章内完整自主 AI；见证人、保管员为受控场景角色。真悟空可急于解释、要求当面比较、拒绝某次候选并排安排；六耳可掩饰、试图换地点、请求先拿包、认输或退出。计划只能使用自己亲历/收到的内容；六耳擅长听闻不等于有权读队聊、他人笔记、隐蔽房间或所有未来查验步骤。

唐僧可以相信错误说法，但 Rules 不将信念转成物权或身份事实。人物可要求补查，不能以隐形好感门槛否定已经成立的可追溯查验。身份核验开放知情选择，不自动强迫唐僧继续收徒、真悟空同行或六耳认罪。

拒绝时可换一个公开等待点、分别递交材料、由本地人把真包撤到中立处，或安全分别。六耳拒绝站台不阻止玩家依据已经存在的完整链认出真正同行者；他退出时只记录其实际走向，未知真身的旁观者不能收到“六耳逃了”的全知提示。未经授权不得搜私人包裹、限制离开或攻击候选。

一名见证者离线/工具被占用按共用恢复处理；授权场景记录有正式请求入口，个人秘密不是替代品。公开核心记录出具失败显示故障与可重试，不随机销毁。真实AI无有效决策时可走已知安全等待点；不能自动作招徒/分别决定。程序因故障结束时使用未完成结果。

## 8. 结局与真实离场

| 结局 | 必须成立的事实 | 实际去向 |
| --- | --- | --- |
| WK-E01 本源相认、再上西路 | 真悟空来源链完整且合法送达唐僧；真包核对并实际回到获授权保管；双方知情决定继续同行；公共工具收尾 | 唐僧、真悟空及实际在队者走到西行出发点；六耳到山后出口或公开独立等待点，不能仍在同行名单 |
| WK-E02 事实已明、各自暂行 | 来源链和真包处理完成；双方作出暂不同行的明确决定；彼此私物妥善处理 | 唐僧到驿后住处/已许可出发点，真悟空到独立去向，保留未和好的实际结果；连续线路按前情契约暂停 |
| WK-E03 行囊保全、身份待查 | 真包已在中立安全柜、取经人已安置；查验仍unknown或当事人暂不作选择；在线团队明确选择结束本局查验 | 唐僧实际回驿，候选到各自公开等候/离开地点；不宣布谁真谁假，不记“已复合/已取经” |
| WK-E04 未完成 | 团队按共用规则提前结束，或技术/在线条件不能维持 | 记录实际位置、未回收物件、已证实片段和未知；不补离场、不写保护成功 |

E03不是自动出现在等待超时后的胜利；必须真包保全、本人安全并有明确收束。被核验者撤回同行同意使旧离场计划失效，不能把其身影已经朝西走过一次算为最终同行。

## 9. CH05 选题门槛的可实现论证

| 主 Spec 门槛 | 本稿的具体机制 | 可证伪检查 |
| --- | --- | --- |
| 两项不可由终局对白替代的调查/协作 | ①沿实际观察锚点取得并校核连续见证，绑定眼前对象；②清单/封口核对真包，修桥铺板后真实取回或中立撤运 | 删除①只能得到unknown，不能定向交接；删除②即使知道真悟空也不能提交E01/E02；单句“都查清了”无效果 |

| 玩家实质改变路径 | 早护送可直接保留身份，晚补查需场景见证；行囊不同安全路线；可相认/分别/保全待查 | 取消所有玩家操作，NPC不能自行宣布E01；结局只等如来/谛听宣布即为设计退回条件 |

这是有限内容状态/现有动作可表达的设计论证，不是 TLC 或玩法实测证明。最大风险是观察链在真实地图里可能变成繁琐的记录拼接，或备用链让调查过于机械；真实试玩若玩家只等NPC给卡片、不能解释因果，应返回设计调整地图与工作，不能宣称门槛已过。独立审查不接受起点后台认证、断点凭重演补齐或单物定真身时，先修此方案；仍无法成立才启用原 Spec 的红孩儿替补。
