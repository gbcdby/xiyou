# 美术方向与设计资料

本目录是《西游记》多人 AI 协作游戏的美术方向、视觉规范与参考证据的统一入口。只保存**整体风味、美术语言与跨资产原则**，不承担页面功能合同、组件坐标或业务数值。

- [整体总纲](guidelines/overview.md)：跨资产稳定的七条关系。
- [视觉语法](guidelines/visual-language.md)：线墨、精度与空间语言。
- [色光与材质](guidelines/color-and-light.md)：色彩职责、明度彩度与材料表现。
- [人物](guidelines/characters.md) · [环境](guidelines/environments.md) · [动效倾向](guidelines/motion.md) · [一致性](guidelines/consistency.md)。
- [UI/UX 共性](guidelines/ui-and-ux.md)：界面与场景融合、图标系统与通用 UX 约束。
- [出图简报](guidelines/art-brief.md)：生成美术素材时的通用模板。
- [参考目录](references/catalog.md)、[来源说明](references/provenance.md)：72 张原始参考与来源边界。

## 边界

参考资料、图片选择、原型运行与真人体验是不同证据，不能相互替代。参考入库不等于采纳画风；新增批次需先确认具体范围与长期入库范围。查阅参考不等于完成视觉验证。

界面实现所依据的视觉约束在任务开始时从本目录读取；本项目界面技术栈与目录约束见 [工程约定](../engineering.md)，产品设计依据见 [初步设计文档](../../初步设计文档.md)。
