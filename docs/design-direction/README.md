## 边界

当前仓库保留了美术规范与色彩提案，**尚未收录原始参考图、总览图或 ART01 文章配图**。旧资料中的 R01—R72、6 张总览与 ART01 的 7 张配图均为待核验的历史记录；规范中的编号用于保留追溯线索，不能视为本项目已经查看或验证这些素材。实际清单见 [参考目录](references/catalog.md)。

参考资料、图片选择、原型运行与真人体验是不同证据，不能相互替代。参考入库不等于采纳画风；新增批次需先确认具体范围与长期入库范围。查阅参考不等于完成视觉验证。

界面实现所依据的视觉约束在任务开始时从本目录读取；本项目界面技术栈与目录约束见 [工程约定](../engineering.md)，产品设计依据见 [初步设计文档](../../初步设计文档.md)。

视觉探索与资料维护使用 [`worker-visual-design`](../../.agents/skills/worker-visual-design/SKILL.md)；依据已确认设计实现或检查界面时使用 [`worker-ui-fidelity`](../../.agents/skills/worker-ui-fidelity/SKILL.md)。本次文档整理不构成出图、素材迁入或界面验收。
