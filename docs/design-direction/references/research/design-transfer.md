# 从通用游戏案例到当前美术方向：只迁移视觉方法

## 来源入口与当前状态

本页保留继承的设计建议。案例与 GP 模式编号分别指向当前仓库技能包的[游戏案例库](../../../../.agents/skills/worker-visual-design/references/game-case-library.md)与[游戏 UI/UX 模式](../../../../.agents/skills/worker-visual-design/references/game-ui-ux-patterns.md)；需要核对原始文章或观察范围时，从这些文件中的来源继续查证。本次只核对文档路径与表述，没有重新浏览全部来源、审阅游戏画面或运行 xiyou 界面。

## 本项目拟采用的五条跨资产方法

| 类别 | 有依据的设计方法 | 在本项目中允许的视觉迁移 | 不迁移的特性 |
|---|---|---|---|
| 美术与信息分层 | Dordogne / GP02：丰富水彩景物与可读文字分别处理 | 先留云光／绢面阅读位置；内容内部平整，外围有笔触 | 不照搬取景功能 |
| 配色变化与一致性 | GRIS / GP03：色域可变、轮廓与材质语法相近 | 身份色保持真实彩度，山水远近与墨线沿用共性 | 不复制章节色板 |
| 焦点与空间 | Monument Valley 2 / GP01：主体关系优先 | 确定一处有记忆点的人景关系，精工集中于焦点 | 不把极简 HUD 当强制要求 |
| 材质与读数 | stitch. / GP02 + GP10：材质密集仍有清楚数字 | 关键字／符号可增强对比，装饰纤维不侵入文字 | 不将刺绣图案直接移植 |
| 输入语义与清楚反馈 | Sky 开发者访谈 / GP10、Spiritfarer / GP05 | 图标与阅读的分层要适合真实手机使用，状态表达有明确含义 | 不复刻社交与管理机制 |

## 更新与验证边界

- 这份转译是设计**采用建议**，不是经过原型或玩家研究的结论。
- 后续提取结论时，应区分官方文字、实际查看的视觉内容与设计推断，并保留具体来源；不能把本页继承的摘要当作本轮已经浏览原始资料，也不据此推测某游戏当前用户偏好。
