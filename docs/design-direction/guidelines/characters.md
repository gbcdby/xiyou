# 人物美术大纲

**清逸、有骨力而精致。** 不以男女划分精度等级，也不强制全员同脸、同衣色、同年龄或同一动作。体型、神情和饰物按角色身份变化，但共享下列绘制语言。

- **脸和发**：五官精确而克制，眉眼、鼻唇、发束的明暗与局部细丝有主次；清冷不等于面部僵硬，温和不等于幼态。
- **姿态**：身体重心、肩颈、手势与服装受力讲得通。可静可动，姿态与角色气质相互解释。
- **衣装**：先理解领襟、袖口、内外层、腰部固定与下摆，再选择纹样。大色面承托少数精工细节，衣料厚薄应与运动一致。
- **材质**：棉麻、绢、纱、玉、金属等有区别；透明衣层只放在合理部位，不能把整个身体结构冲淡。
- **身份与多样性**：一处发饰、衣缘、武器或随身物可以成为识别焦点。不同年龄、性别与体格拥有真实差别，同时共享工写关系。
- **画面关系**：人物色面从环境中清楚分离，外围发、衣与景物可共享气流方向，制造与天地相连的感觉。
