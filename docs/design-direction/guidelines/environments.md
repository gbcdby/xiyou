# 环境与东方幻想空间

## 核心母题

松、竹、枝叶、溪流、白水、天光、雾山、庭台与岩石构成自然基础。可引入悬浮、云带、极远建筑、鹤影等非常规尺度元素，但不要求每幅都有它们。

## 精致度和疏密

选择一处有触感的近景（树、石、水岸或器物），中景承接遮挡与尺度，远山逐渐融入云天。复杂景物与大片安静区域成对设计；不要把每棵树、每座山、每栋建筑都处理成同等细密的焦点。

## 温度与仙气

光与空气以清亮白昼为主，暖日、冷泉、雨后、花影或秋风可以切换。治愈感来自空间可停留、声色不拥挤；仙气来自比例、云水贯穿、悬浮或远近变幻，不靠浓重夜景和满屏亮点。

## 为信息预留空间

当环境为 UI 背景时，主动安排一片连续的安静浅色阅读区域，让云水、色面与文字彼此衔接，避免后贴厚重大板。背景本身保留有层次的细节，只在文字后方控制局部纹理。
