# 总体风味 · 清逸仙境、工写相生

## 一句话

**以清逸的东方幻想人物承载情绪，以有骨力的线墨和透明矿彩塑造材质，借留白、虚实、云水流向和自然光色形成一眼可记的仙境气韵。**

用于界面时：大主调连贯，场景以浓淡块面和少量线骨概括，颜色保留物件归属，局部亮色适量。以下人物与材质精工原则服务少数焦点，不要求界面山石、枝叶、衣纹处处细描。

## 跨资产稳定的七条关系

以下 R 编号来自继承的规范，原图尚未迁入 xiyou；它们用于保留追溯线索，不构成本项目已查看或采纳对应画面的证据。状态见[参考目录](../references/catalog.md)。

1. **工写相生**：面部、手、发束、领襟与一两处身份饰物经得起近看；大衣面、远山、云气与石边可以笔墨概括，不平均堆细节。[例 R13、R44、R50、R54、R68](../references/catalog.md)
2. **虚实有层**：在同一空间中同时保留清楚焦点、适度中景和渐隐远景。失边用于画面外围，不能使主要形体失真或文字模糊。[例 R04、R22、R25、R49](../references/catalog.md)
3. **明亮但有颜色**：大面积晴昼亮底里保留清楚主体衣色、冷暖回应和少量墨色深点；允许红、青蓝、绿、杏橙、紫等成为完整色面。[例 R14、R45、R54、R69](../references/catalog.md)
4. **酷而不重**：用眉眼、姿态、颈肩重心、领腰结构与衣云的方向感表现清峻。无需统一加厚轮廓、加甲胄或压暗背景。[例 R16、R53、R72](../references/catalog.md)
5. **自然与仙境共生**：林、松、竹、溪、水、雾有可停留的生活气息；用尺度、悬浮、薄雾与少量非常规形态制造幻想，不以建筑和特效数量取胜。[例 R03、R24、R29、R49](../references/catalog.md)
6. **局部华彩**：玉、细金、银、织纹、纱或朱砂可作为身份与光线的精工亮点，安排有主次，不变成每处都有高光与镀金边框。[例 R54、R56、R68](../references/catalog.md)
7. **视觉与信息相融**：用于 UI 时让浅天光、云面、绢面或淡彩成为自然阅读承托；文字、数据和状态拥有清楚的边界与对比。[UI 视觉原则](ui-and-ux.md)

## 气质坐标

- **古风**不等于古代符号密度。应从线的提按、形的构成、设色层级、节奏与空间建立风味。
- **仙气**不等于透明度、光圈和满屏粒子。人物形体明确，云水与远缘适度轻盈，留出呼吸。
- **精致**不等于复杂。焦点的工艺精度、材质区分、局部静动与边缘控制更重要。
- **治愈**不等于软萌或甜腻。自然尺度、可亲近的场所、温和但不失锐度的光线能创造舒适感。
- **惊艳**来自明确的画面记忆：一条贯通的水光、松影与云海的强弱、衣与云的线势呼应。仍需实际成图验证，不是宣称达到。

## 允许变化

人物年龄、体型、衣色、材质、季节和画面构图可大幅变化。统一性优先由**墨线语法、工细分配、色彩职责、空间虚实和材质逻辑**建立，而不是机械共享同一块青绿色滤镜。

## 当前不采纳的倾向

大面积暗底或夜景 UI、粉色云雾覆盖一切、均匀灰白去色、厚重的重复框板、逼真的岩石与满密微景、堆饰而无身份焦点、通用商业图标与绘画割裂。它们描述的是应避免的**结果**，不限制有目的的局部浓墨、红衣或复杂纹样。
