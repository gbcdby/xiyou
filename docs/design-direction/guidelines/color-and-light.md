# 色彩、光线与材料 · 现行总体方向

## 目标

**白昼通透、有鲜明固有色、冷暖可往来，清逸而不苍白。** 让人物与自然拥有色相和材质差异；结构墨色有限但必要；界面的读数处平静、清楚。配色不是单独的调色板任务，而是人物、环境、材质与局部信息之间的关系。

## 六个色彩职责

| 职责 | 项目语法 | 避免 |
|---|---|---|
| 主体身份色 | 红、青蓝、翠绿、杏橙、烟紫等可拥有完整衣面 | 全员换色时只剩同一青灰 |
| 环境空气色 | 树影、山水、溪流和天光建立深浅与冷暖 | 把大气色蒙在所有物件上 |
| 结构墨色 | 脸手衣层与重要形体节点的清楚深点 | 使用大面积黑底制造厚重 |
| 桥接浅色 | 暖白、冷白、灰石、绢色协调邻接色面 | 全画泛白使身份色消失 |
| 焦点与材质色 | 少量朱砂、玉、细金、铜、银与光斑 | 每个角落都发光、镶金或闪亮 |
| 信息承托色 | 云面、浅天光、淡绢／轻色面，用于可读文字 | 复杂山石和动态笔触直接垫在字下 |

## 五个重要配色判断

1. **明度阶梯**：先确定主体与远山的可见关系，再细化色相。近处可有浓墨，远处减少纹理和局部对比。
2. **彩度面积**：让鲜明衣色成为有体量的身份面，环境采用相对平静的大色面；没有固定 60/30/10 的数值硬线。
3. **冷暖邻接**：冷衣与暖光、暖衣与冷水都可以成立；在两种鲜艳区域相接处，允许用领口、内衬、墨线或云白桥接。
4. **材料不同光**：布为宽面柔反光、玉有节制的透感、金属仅少量准确高光、岩石哑光留纹、水面以透明和方向线塑造。
5. **明亮不等于低对比**：浅底仍需要清楚的墨色结构与准确的阅读颜色，不能把强调色全部兑灰。

## 人物与独立插画的可选关系（未锁定）

- **晴青配暖杏**：晴空与云白承托蓝与杏的反差，主体颜色应属于实际衣物。
- **朱衣配玉山**：绛朱与青玉互相回应，红只集中身份色与少量重心，不红遍所有组件。
- **松绿配金光**：绿与暖金分布在植物、衣层和光中，用灰石和浅绢连接。
- **烟紫配浅金**：紫、银、浅纸白与少量暖光，避免深色面板或夜间默认。

以上均为 **设计提案**，既非用户原图精确采样，也非玩家大众偏好的统计。它们可用于人物身份色或独立插画；仍须遵守[总纲](overview.md)的线墨、精度和空间语言。

## 这轮新增的可复算检查

色板数据位于 [palette-directions.json](../tokens/palette-directions.json)，声明了 10 组**明确的纯色前景／背景配对**，可由通用 skill 的 `scripts/color_check.py` 检查。其中正文按 4.5:1，必要符号按 3:1 的工作阈值；这些是指定条件下的计算，不代表真实画面全部通过 WCAG 或平台检查。

色板里 `soft_gold` 等偏浅的装饰色**不能自动作为小字颜色**。如果要把它当成文字或必需状态符号，应重新选择色值并计算对比；对透明叠色、纹理、镜头运动、字体缩放仍须另做视觉／设备验证。

参考源 R14、R45、R54、R69 等记录于 [catalog](../references/catalog.md)。关于明度、彩度、色彩面积、邻接与验证方法，参见独立交付的通用 skill：`references/color-systems.md`（跨压缩包引用，不作为本项目相对链接）。
