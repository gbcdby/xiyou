# 线墨、精工与虚实语言

## 线与面

- 画面最重要的结构由细线、浓淡色面和合适的硬边共同建立：脸、手、发根、领缘较清楚；衣摆、云水与远景逐渐放松。
- 线条应有提按、轻重、疏密、断续；枝干与石面可以更粗，细金属或玉饰连接可更细。
- 色层以薄染、留底、局部浓色变化为主。尊重对象固有色，不使用统一古旧滤镜或统一发光雾。

## 细节预算

| 职责 | 适用区域 | 判定依据 |
|---|---|---|
| 精工焦点 | 眉眼、双手、关键衣层、标志性发束／器物、UI 字符图标 | 放大看连接准确，缩小仍能识别 |
| 概括承托 | 大衣面、山石整体、成组植被、中景建筑 | 能读出形和材料而不碎乱 |
| 安静留白 | 云天、水面、简化林冠、信息阅读背景 | 承托主体，避免无意义竞争 |

## 空间和气势

近处不一定全细，远处不一定全虚；以是否是焦点决定边缘和密度。前景可留一处强墨，远景保留宽阔轻蓝灰和暖光；云、水、衣带能够形成少量贯穿全画的方向线，但不能令所有元素一起转成强烈旋涡。

## 精致的诊断

“土”“像宣传海报”“不够仙”时，不首先增加金框或粒子。依次检查：造型轮廓是否模式化、脸手是否粗糙、衣层是否不合理、石景是否平均锐利、设色是否统一滤镜、画面有无一处能记住的构图关系。
