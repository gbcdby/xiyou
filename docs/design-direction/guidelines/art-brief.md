# 通用出图简报模板 · 只写视觉大方向

用下列内容组织创作，不包含任何具体页面功能数量或布局坐标。

**世界情绪**：明亮白昼中的国风幻想，清逸、安静、带骨力与仙气；自然光和奇幻想象共存。

**造型**：人物身份明确，姿态有真实重心，脸手与关键衣层工细；大衣面概括，衣饰只有少量有意义的精工焦点。

**空间**：一处主要景物关系，近中远对比递减，云水或衣带形成有节奏的线势，留出呼吸空域。

**设色**：暖白／冷白作为空气与阅读面，主体有明确的红、蓝、玉绿、赭金或烟紫身份色，辅色与环境有冷暖回应；少量墨色深点控制结构。

**材质**：有提按的中国画线墨、透明矿彩薄染、局部精细玉金丝织，避免全图同一锐度、同一灰雾或同一颗粒。

**UI 视觉（如本图包含界面）**：信息自然坐落于低干扰的浅云／绢面中，图标成族，文字与状态高可读；轻巧分组，不用厚重的连续大背景块强行切开场景。

**页面输入另附**：真实功能与状态、保留的布局锚点、本轮允许改变的范围、画风参考和布局基准各自用途、首屏／长页用途与目标比例；不从画风参考复制页面结构。生成图中的数值、文字、图标仍需对照合同。

**验证问题**：缩小一眼先看到什么？是否有独特气韵？人物近看细节是否准确？颜色有实际分工吗？文字阅读是否不受场景干扰？

以上为总体方向，可由实际素材和用户后续决定修订。未确认的页面内容应由单独业务规格提供，不能由 style guide 自行添加。

## 本轮新增的设计过程

- 出图前先描述**一处能被记住的人景关系**与三个细节级别（精工焦点、概括承托、安静空域）。
- 配色必须说明主体、环境、桥接浅色、深墨、焦点和阅读承托分别服务什么，不写“高级配色”却只列 HEX。
- 若包含界面内容，先给文字留出干净色域，再让云光、笔触、色面自然连接；信息字形和点击可供性不做水墨失边。
- 对比方案说明固定变量；变更多个因素的结果只能评价总体方向，不能声称颜色单独获胜。
- 产物完成后记录正常、缩略、局部与最差背景检查；未生成产物不能写“验证通过”。
