# 跨资产一致性

**共同的是画法语言，不是角色颜色、背景位置或组件排列。**

| 稳定 | 可变化 |
|---|---|
| 线条提按与精工焦点规则 | 不同身份的五官、发型、体态与装饰多少 |
| 颜色有职责，冷暖和深浅成关系 | 季节、主衣色、环境主题色 |
| 近中远虚实与有目的留白 | 自然与建筑意象、场景密度 |
| 绢、水墨、矿彩等材料逻辑一致 | 角色可以偏华丽或简洁 |
| 图标同族、信息阅读承托稳定 | 不同界面可以采用不同信息布局 |
| 亮日与清逸、有骨力的总体气质 | 暖色或冷色担任主调 |

## 检查组合

同一人物进入不同光色场景、不同角色处在同一场景、图标放在精细背景上、文字遇到丰富色面时是否仍成立。不要仅靠让所有图共享青绿色遮罩获得所谓一致。

用户明确删除的试验画法不应出现在现行方向表、推荐样板和正向简报中。原始来源仅作为可追溯素材保留。

## 跨角色／场景／UI 的回归矩阵

| 对照条件 | 观察对象 | 风格应保持什么 | 允许变化什么 |
|---|---|---|---|
| 同一人物 × 两种天气光 | 肤色、衣领、布料色面 | 线重、衣层逻辑、身份色的主要职责 | 环境色温与少量反射 |
| 两个不同身份 × 同一场景 | 表情、造型、局部装饰 | 工细焦点与远景概括方法 | 年龄、体型、服色、饰物等级 |
| 同一信息 × 两种复杂背景 | 字形、图标、信息承托 | 可读性、状态含义、共同材料语言 | 信息区域周边景物与轻盈托面 |
| 两种配色关系 × 同一画法 | 主辅色、桥接、深墨 | 空间明暗节奏与墨线语法 | 冷暖分工和显色面积 |

对照结果应记录可见的证据与反例，不能凭“画面都挺像”宣布稳定。
