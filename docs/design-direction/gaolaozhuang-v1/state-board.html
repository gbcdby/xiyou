01 门、支撑与通路

◇ 铜封未解

先核对安全条件

门仍然闭合。普通钥匙不适用，也不因此消耗。

门外承力点、人物退让区各自可见。不能只把交互按钮变为“已开启”。

✓ 支撑已锁定

准备已经留下

安装者可以离开。短暂掉线不会让支撑自动松开。

单侧完成就只画单侧锁定；另一侧仍是待装材料。计数、贴图和世界事实必须一致。

✓ 通路已开放

门开了，安置还没完成

真实翠兰需要同意安排、实际走出，再确认安全。

本排是状态构图示意；正式铜封、门撑与门扇美术需独立分层制作。

02 接受路线不等于到达

正在前往

路线已受理，位置随服务端确认推进。

已到达，可查看

距离、目标状态重新核对后，开放交互。

◇ 暂时无法靠近

通路受阻，保留物件，原排队操作取消。

? 正在确认结果

连接恢复后查询原操作，不能再交出一份。

03 一样的外貌，不同的合法知识

真实翠兰 · 已安置的本人

翠兰
✓ 已确认安置

她的物品、随行同意与安全事实仍归她本人。其他同外貌角色不能替代。

尚未识破者的视角

翠兰
◇ 可当面交谈

与真实翠兰使用相同外貌资产。名字、收据、物主提示均不附带隐藏真身。

已合法知道真相者的视角

悟空 · 借貌
✓ 你已知情

外貌不换成猴脸以方便调试。合法获知后才更新姓名和必要说明。

04 本人同意、随行与撤回

◇ 待本人回应

已提议去前院客房

带路者：高才。她尚未回应，角色保持原处。

父亲、玩家和同外貌人物均不能代答。

● 随行中

一起去她同意的地点

可以暂停；更换地点或带路者需要重新约定。

到了目的地仍要等本人确认安置。

— 原安排已撤回

先停下来，再商量

原路线不再完成安置，不把迟到回调算成成功。

已完成的救援，不因撤回会面或借貌而回滚。

05 证据、承诺与可恢复反馈

✓ 亲眼所见

铜封仍在门上

记录观察者、地点与当时状态。状态变化后保留历史，不当作现况。

◇ 某人的陈述

“我曾在等候来客”

保存说话者和合法接收者。听说过，不等于事实已核实。

◇ 承诺未执行

愿意归还工具

工具仍由原持有人保管。只有真实交接才显示归还完成。

Ⅱ 等待同伴

当前只有一人在线

世界准备状态保留，剧情和随行不继续推进。

宽限结束后才开放相应“暂告一段”；单人离开不关闭他人的房间。

06 三种真实结果

GZ-E01

自愿同行

双方有效决定、公共物归还、师徒与八戒实际到达出发点，才显示同行结果。

GZ-E02

各走各路

翠兰安全、后宅开放、公共物归还，人物实际分别；未决不写成“八戒已拒绝”。

GZ-E03

暂告一段

逐项留下救援、安置、查证与归还进度；不以统一失败覆盖已发生的事。

墨、青、朱、赭、烟紫分工；状态同时使用文字与符号。
