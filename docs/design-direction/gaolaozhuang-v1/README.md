## 可见图与复现

本轮设计图和必要图像已保存于本次任务的授权交付中；当前工作区可直接审阅。对外发布的素材恢复入口尚未获得授权，因此本候选不登记个人资源标识、下载链接或归档元数据，也不声称仅克隆仓库便能恢复全部图像。自动审批曾拒绝把私人交付入口写入GitHub，后续发布不得绕过这一限制。

[assets-manifest.json](assets-manifest.json)登记样页所需图像的路径、尺寸、来源类别与用途；图片二进制不进入Git。取得授权交付后，将其中 `assets/` 放到本目录的 `assets/`，七个精确视图与关键状态板可供比对。没有这些图像时，样页的视觉复现仍有缺口；[状态板](state-board.html)的原生图形和文字可独立查看。原庭院与高才沿用下方已有项目入口，新五人静态造型与庄外短路的对外恢复入口仍待处理。

打开 [main-view.html](main-view.html)；独立样页没有后端、模型或世界状态，只有固定设计样例。参数 `?state=main|follow|road|dialogue|inventory|notebook|recap` 对应主视图、随行、庄外、对话、行囊、手记与回看。底部入口可以切换相应阅读面板，Esc关闭面板；操作按钮只提示当前为设计样页，不生成世界事实。

[state-board.html](state-board.html) 展示门/支撑、移动与未知结果、按观察者身份、本人同意/撤回、证据/承诺、人数不足与三类结局。SVG门和支撑明确属于状态示意，后续需要正式分层贴图。

源码无依赖，可用现代浏览器直接打开，或在仓库根使用静态HTTP服务访问。基准截图视口为1600×1000 CSS px、DPR 1；状态板为1600px宽完整长图。正式实现不可将这些整屏截图当作运行背景。
