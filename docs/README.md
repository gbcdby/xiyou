## 使用规则

- 设计约束放设计或 Spec，工程约定放工程文档，任务状态放 GitHub Issues/PR；索引只保留必要摘要与链接。
- 每项“已完成”绑定可读取的提交、PR 或检查记录。外部事实需可追溯来源；旧会话引用标记、其他项目的历史记录与计划目录不能证明当前能力。
- 用户的新决定修正相关权威文档；保留决定的日期、适用范围及其替代关系，避免复制另一份状态清单。
