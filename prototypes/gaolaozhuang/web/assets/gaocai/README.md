# 高才玩家角色：原型试接素材

本目录是用户明确要求“放进原型看表现”后的中间运行候选。素材尚未通过完整动画或最终美术验收。所有图像均来自现有透明 PNG，未声称它们取自原生 GIF。

## 内容和来源

- `walk/{s,se,e,ne,n}/00.png` 至 `07.png`：40 张真实行走帧。
- `idle/{s,se,e,ne,n}.png`：5 个静止方向，明确选自原包 `basis/gaocai_basis_<dir>_candidate_v2.png`。
- `manifest.json`：运行参数、逐帧真实尺寸、源文件/裁分/哈希、镜像和已知质量问题。
- W←E、SW←SE、NW←NE 由运行层围绕角色落点水平镜像；不另存 24 张镜像 PNG。

45 张 PNG 总计 6,737,985 字节，全部与来源文件逐字节相同。40 张行走图也重新核对了原图矩形裁分的 RGBA 像素一致性。保留源低 alpha 噪点，没有清理、描补、换肢体、变形或拼造动作。

来源包：`gaocai-5native-3mirror-material-study-v1.zip`；SHA-256 `36a9b4b21b5f265968e24b8a30b037429fc3e0083baa00de61ad385361b7a6cc`；Library ID 记录于 manifest。源包保留在本次候选的 `source/`，完整解包及原始说明保留在 `extracted/`。

## 渲染合同

逻辑角色 `(x,y)` 是地面落点。保留原型按 y 排序的人物层。

每帧对象与 idle 对象都有 `file`、`width`、`height`、`footPivot {x,y}` 与 `scale`。`scale` 已是最终地图单位/源像素，**不要再乘一次 `groupScale`**。

```js
ctx.save();
ctx.translate(actor.x, actor.y);
ctx.scale(direction.mirrorX ? -1 : 1, 1);
ctx.drawImage(image,
  -frame.footPivot.x * frame.scale,
  -frame.footPivot.y * frame.scale,
  frame.width * frame.scale,
  frame.height * frame.scale);
ctx.restore();
```

名字、选择环、持物标识等继续围绕 actor 落点正常绘制，不随 sprite 镜像。图片加载失败时应采用实现侧稳定回退，不抛异常中断游戏。

目标主体高为 76 地图单位。按来源组一次性记录 alpha>16 的参考主体高度，再给整组统一等比缩放；不逐帧追随紧 bbox 拉成等高。所有行走帧测得主体显示高度为约 73.71–77.28 单位，保留蹲起变化。

## 帧与状态

- 行走按 00→01→02→03→04→05→06→07 循环，初值各 90ms，一周期720ms。来源查看包为100ms；本次90ms是试接参数，不代表已与205单位/秒或其他移动速度标定。
- 以实际有效位移判定移动，方向用实际位移。转向保留当前相位，避免方向边界反复重启00。
- 停步显示对应 idle，保留最后一个有效位移的八方向；碰撞阻止位移时不能继续原地播放行走。
- 仅玩家操作的高才使用此候选。玩法、碰撞和角色逻辑不属于素材变更范围。

## 本轮允许试接的边界

用户授权直接看原型表现，无需等待完美美术。S/N 仅静态换腿可读；SE 完整双步仍不确定；E 保留完整原v1，00→01、04→05步距偏急；NE 旧00–03配新04–07，06换腿改善，但04/05近臂反摆失败，前后批次比例与接缝未通过。三镜像会反转交领及光照，此次只针对普通空手行走。

本轮查询到的 `image_gen__imagegen` 契约仍没有 model、GIF/output_format 或动画时长控制，因此没有重复先前返回静态图的请求。此结论仅描述当前工具入口，不推断产品不支持原生 GIF。

PNG 可进入既有私有 Sites 源码仓库或外置运行资产包。GitHub 项目仓库按约定只放文本 manifest 和恢复说明，不加入 PNG、原ZIP、dist 或 evidence 二进制。最终正式保存由交付 worker 处理；本目录是素材 worker 的中间候选。

## 恢复方法

从 manifest 中的 Library ID 恢复源ZIP，核对上述SHA后解包。对 `native[d].walk.frames` 和 `native[d].idle`，将原包根目录下的 `sourceFile` 字节复制到本运行目录的 `file`。逐项核对 `sha256`；总数应为45。保留本 manifest 的 pivot/scale/90ms 配置即可重现本候选，不需要从GIF解帧，也不需要重新绘图。
