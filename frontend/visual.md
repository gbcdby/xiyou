# 高老庄渲染合同

依据：[GZ-VIS-01 / v1.1](../docs/specs/gaolaozhuang-visual.md)、[#33](https://github.com/gbcdby/xiyou/issues/33) 和 [公开造型协商](../protocol/spatial-appearance-v1.md)。本文件描述运行实现，不替代设计采用、独立审查或全素材验收。

## 权威位置与公开外观

背景、角色、物件、路线共用 SVG 逻辑画布。人物位置始终是服务端授权脚底；标签在独立 CSS 像素层中排布，以同一 `xMidYMid meet` 映射定位。不能为了文字移动权威人物。按钮标签至少 14px、44×44px，人物/物件的图上命中区也保持至少 44px；容不下的标签保留对象列表入口。

新客户端在创建、加入、HTTP 和 Socket 鉴权统一声明 `spatial-v2,spatial-appearance-v1`。只用当前授权 `appearanceId` 选择美术，不能按称呼、观察者知识、`entityRef` 或隐藏真身选择。外观版本变化时销毁旧人物资源状态；旧服务缺字段或缺本地资源时显示同一中性回退。角色称呼和可见编号继续由原授权标签规则负责。

## 确认移动与步态

`ConfirmedMotion` 只采样前后两次合法投影之间的已确认路径，不外推未来路径，不回写服务端位置。角色朝向和步态路程从同一条已确认折线计算，转角保留路径顶点。停止使用末段朝向的独立站姿；换视图、场景、控制代次、外观代次或连续轨迹缺失时不延续旧步态。

高才使用原帧的 `footPivot` 和最终 `scale`，不再叠乘 `groupScale`，不逐帧按边界归一化。镜像只作用于脚底局部的图像，姓名、选择环、持物权与操作目标不镜像。系统减弱动态模式直接呈现确认位置和站姿，文字与操作状态保留。个人打开阅读区不会暂停另一个玩家。

## 布局与资源故障

默认镜头跟随授权本人；“查看全图”使用完整场景，“回到角色”恢复跟随。桌面阅读区占独立侧栏，窄屏改为纵向阅读；不会把 1600px 画面等比缩成手机页面。目标、本人与随行者的图像边界获得额外标签避让空间。坐标标签不会改变地图世界位置。

图像预载失败时回退同朝向站姿，再回退中性图形，点击区和授权文字继续存在；按“重新载入图像”可重试。素材位置与正式缺口见 [运行图像说明](public/assets/gaolaozhuang/README.md)。中性回退和庄外概念不代表完整正式美术通过。

## 实际检查入口

`node frontend/tests/gaolao-art-browser.mjs` 启动隔离真实 PostgreSQL、正式服务和 Vue，以独立 Chromium 上下文执行点地、八向转向、停步、阅读时同伴行走、减弱动态、390×844 重排、真实场景出口与资源失败恢复，并生成原始截图和连续 WebM。浏览器与录像编码器需在运行环境可用，缺依赖会失败，不静默跳过。原始失败、截图、录像与源身份保留在运行时指定的证据目录。

这条检查是作者自查，不是真人趣味、手机真机、真实模型或全部 NPC 动作验收；三者不能由自动浏览器代替。正式阶段结论仍由 #29 对固定候选给出。
