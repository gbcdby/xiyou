# Design Direction Project · 美术资料入口

此为可选的美术参考资料模板，`init` 默认放到 `docs/design-direction/`，也可指定兼容目录。已有共享 Spec、规范和页面合同保持原位；只需局部设计时取用相关提示，不初始化整套目录。`init` 仅补缺，学习文件按需采用。本模板不预设画风，guidelines 只承载整体美术关系，不收录具体页面功能合同。

在本次要求或已有授权涵盖长期入库时，使用 `references/inbox/` 接收并运行通用 skill 的 `ingest` 登记，再逐项审阅并更新规范。搜集中的候选仍留会话目录。注册文件不等于视觉审阅。

## 可选的研究与验证记录

研究与验证按需写入项目已有页面、原型记录或决定条目，采用与实际验证分开。init 不建立独立的评审日志或变更历史目录；可选记录表保留在技能 assets/validation-template 中，按需填入已有文档。

`worker-visual-design` 交付美术方向与界面规格；公共规范和页面合同沿用项目既有位置，实现与独立检查交由相应 worker 接续。本模板不自动生成页面约束。
