# 可复用视觉语法

## 工细、概括与留白

精致感不等于细节平均增多。先划定 **精工焦点**（例如五官、重要衣缘、材质连接）、**概括承托**（较大衣面、景物色面）和 **安静区域**（空间呼吸、文本背面）。在不同尺度上维持同一主次。

## 线、面、色、势

分别定义轮廓靠线还是面成立、线的轻重与断续、色层的厚薄与留底、形体怎样由亮暗与边缘区分。静态画的衣带、枝叶、云水可以形成视线流向，但不要由此声称已有可运行动画。

## 空间和构图

“近清、中虚、远淡”是可选方法，不是全部画风的固定模板。决定焦点后，利用遮挡、轮廓清晰度、色彩纯度、局部对比与纹理密度安排前中远。留白可以是天空、水面、简化树冠或平稳色面，不局限于纯白。

## 气质校准

“更酷”“更温柔”“更仙”“更高级”需要翻译成具体选择：眉眼与姿态、轮廓速度、衣装重量、光线形状、配色对比、纹样密度与材料品质。不要用强行变暗、叠特效、加边框或一味减饰代替设计。

## 舒适度反馈的诊断

用户说“刺眼、太饱和、杂乱、看着累”时，先保留其感受，再核对画面中的成因；用户提出的饱和度猜测不能直接当作已验证原因。

| 观察层 | 要找的画面证据 | 对应设计动作 |
|---|---|---|
| 色光关系 | 亮部面积、局部彩度及相邻区域的反差；高亮是否到处出现 | 调整有问题的颜色职责、面积或邻接，保留必要的阅读与状态对比 |
| 形体与细节 | 碎亮边、纹理、小轮廓是否均匀铺满，远景是否与主体同样精描 | 先把形体归并成连续色面，集中精度，留下平稳区域；不要只降低整图饱和度或模糊全图 |
| 整页注意层级 | 人物／场景焦点、装饰、图标、徽标、按钮是否同时争抢 | 将美术与 UI 放在同一张画面中分配主次，按任务保留必要强调，统一同类图标的精度与材质 |

根据证据选择调整，不机械执行全表。对象多也可以有秩序，低饱和也可能满屏碎对比；平均亮度／饱和度不能替代分布与多尺度目视检查。安静区域可有颜色与中间调，不把“柔和”固定成大片纯白、灰雾或暗底。若问题指向信息组织，转入[界面重构](interface-design.md#整页重构时的功能与视觉边界)。

## 风格继承边界

分别记录用户赞赏的是画法、配色、气氛、人物形象、物料还是局部关系。认可画风不代表锁定布局，认可人物色彩不代表其他身份只能换色。明确弃用的方向不得回流到正向规范。
