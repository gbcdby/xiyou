# 色彩、光与材料的通用方法

- 先识别色彩职责：环境主气氛、人物身份色、辅助层次、结构深色、阅读承托、焦点色。不要只从图片提取一串 HEX 而不标注用途。
- 依照 **明度主次 / 冷暖往来 / 面积分配 / 材质固有色 / 局部纯度** 建立色彩关系。大面积偏静，小面积可以饱满；这不是强制比例。
- 明亮不等于漂白、全局降饱和或增强泛光。保留有辨识度的彩色主体、适当结构深点与清晰的阅读面。
- “高级”靠相邻色协调、焦点明确、材质反光有别、精度集中、场景光色统一；不是固定配色模板或某个时代的装饰总量。
- 配色变体的比较须说明哪些不变：画法、主要对象、光照、环境或布局。若全都同时变化，只能研究整体偏好，不能归因于颜色。
- 区分从图实测、视觉近似、设计提案。色值对比计算只适用于指定前景/背景，不能代替成图、真实尺寸和不同设备的可读性验证。
- 衣物、发丝、纱、玉、金属、石、木等材料，各自依靠不同的边缘、折射、阴影和纹理讲述，不靠统一滤镜。
