# 界面设计核对与验证交接

先按本次设计改动和产品实际支持范围选取相关项。设计自查可检查规格与已有图像；运行验证由适当执行者在目标平台进行。逐项保留证据、未验证项和理由，不把清单当成结果。

## 规范与视觉

- 使用当前有效的画风、公共组件和 token 合同，局部例外有来源与范围。
- 同用途控件沿用已有模式或合理变体；尺寸、形状、字体、颜色、间距和状态没有无理由分叉。
- 主次信息、关键状态和动作在实际显示尺寸清楚；图标、数字、材质与场景共享设计语言。
- 保留已确认布局锚点和业务能力；被收纳的内容有新入口、必要通知和返回路径。
- 调整覆盖背景、文字、图标、控件及交界；主调、固有色、点色和细节密度有分工。
- 正文在纹理、透明叠色和动态最不利背景下可读；纯色色对计算仅覆盖声明的颜色。
- 长文本、大数、空态、字体放大和资源加载前后仍有明确布局规则。

## 操作与状态

- 视觉尺寸与真实命中区分别定义，数值写清平台单位和依据。
- 区分本任务适用的可点、选中、不可用、处理中、成功、失败和未知结果，不只靠颜色。
- 区分返回、关闭、展开、跳转、预览与提交；定义上下文、草稿和错误恢复。
- 反馈对应真实结果；演出结束不代表业务成功，重复操作、离开重入和中断有明确语义。
- 动效说明目的、触发、时序、中断及减少动态路径，保持关键文字与状态可理解。连续动效的实际路径与录屏核对交给 `worker-ui-fidelity` 或对应验证者。

## 平台验证输入

| Web | 原生 App／其他目标平台 |
|---|---|
| 支持的视口、缩放、断点、滚动和固定区 | 支持设备、安全区、系统栏、键盘和滚动容器 |
| 键盘任务、焦点、弹层进入与退出 | 点按、手势仲裁、返回与关闭行为 |
| 语义控件、标签、错误和辅助阅读顺序 | 辅助技术、阅读顺序、大字号和命中区 |
| 图片占位、长列表、资源和动画表现 | 原生资源、长列表、并发动效与生命周期 |

只涵盖产品支持的主题、设备和方向。平台准则采用前查官方资料并说明适用性；网页截图不能充当原生运行证据。

## 证据与交接

- 图片候选标明编号、视口、首屏／长页用途与采纳范围。区分用户确认、agent 提案、静态自查和目标平台观察。
- 有确认图且需要据图实现时，交给 `worker-ui-fidelity` 基准、版本、素材、布局／字体约束、允许差异和相关状态。它维护截图比较、动态证据和修正复验流程；本页不复制其阈值或跨技能文件路径。
- 通用实现交给 `worker-implement`，产品验收和独立审查分别交给 `worker-verify`、`worker-review` 或调用者指定角色；给出检查对象、环境、输入与可观察结果。
- 按 [项目学习](project-learning.md)在授权内更新设计结论及复用入口。只读请求保留建议，未运行的检查明确留待后续。
