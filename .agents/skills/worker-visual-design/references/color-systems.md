# 高级配色的可执行研究与设计方法

**核心判断**：颜色之间的关系、面积、材质、明暗和空间分层比一组固定 HEX 更重要。颜色流行趋势不是可复制公式；“高级”是设计评语，需要具体画面证据。

## 1. 给颜色分配职责，而不是先给对象套滤镜

| 角色 | 任务 | 高风险误用 |
|---|---|---|
| 主体身份色 | 让人物／重点对象拥有可辨色面 | 主体被环境统一染成一个色相 |
| 环境空气色 | 表达时段、湿度、季节与远近 | 高强度气氛色漫过全部层次 |
| 结构深色 | 定义轮廓、转折、文字和功能状态 | 大量纯黑压暗所有物料 |
| 桥接中性色 | 协调冷热对象与材质转换 | 漂白并抹去对象固有色 |
| 局部焦点色 | 层级、特殊物料、行动反馈 | 每个按钮／每件饰品都用高纯度色 |
| 阅读承托色 | 在信息处保留平静、高对比的底面 | 色板通过但实际背后是花纹或动态 |

## 2. 六个关键变量

1. **明度 Lightness**：远近与主次要有阶梯，不能只看色相。观察近景墨重、远景淡色是否有理由。
2. **彩度 Chroma**：高彩度集中在关键对象，低彩度承担背景或桥接；不要全局统一减饱和。
3. **色相 Hue**：冷暖互答可以分布在人物／环境或光／影，不要求一律互补色。
4. **面积 Area**：颜色占多大画面及是否连续，比色卡上块与块的相邻排列更影响观感。“60/30/10”只能是启发，不是可验收硬指标。
5. **邻接 Adjacency**：两种鲜明颜色直接碰撞时，可用衣领、内搭、浅纸面或细深线作桥接。先修邻接，再考虑换全部色值。
6. **材质 Material**：金属小面积高光、布料宽面柔光、玉的透感、石的哑光各有不同；不要使用相同的镜面发光。

## 3. 五种可比较的关系，不是固定色板

| 关系 | 何时有效 | 容易失败 | 修正思路 |
|---|---|---|---|
| 冷环境×暖主体 | 希望主体鲜明、环境开阔 | 暖色遍布界面抢视线 | 暖色集中主体或少量路径节点 |
| 暖环境×冷主体 | 有自然光与清晰衣色 | 冷主体失去体积 | 增加局部结构深色与冷暖反光 |
| 邻近色＋冷暖点色 | 希望安静连贯 | 全图像一层单色滤镜 | 通过不同材质／明度拉开层次 |
| 中性底＋两个角色色 | 多角色、多身份比较 | 两色到处争强 | 明确一主一辅与桥接区域 |
| 大面积淡彩＋局部浓墨 | 水墨、绢本、绘本 | 黑墨压重或淡彩泛白 | 墨只担结构，局部保留鲜明固有色 |

## 4. 对比实验必须控制变量

- **只比较配色**：固定构图、人物、光向和控件形态，改变颜色的职责与邻接。
- **比较总体画风**：允许人物、材质和布局一起变化，但结论只能说“整体偏好”，不能称颜色单独胜出。
- **比较一致性**：同一角色换两种光色、同一场景放两种身份色，检查是否仍在一个体系里。
- **用于 UI**：把视觉气氛与文字／符号区分。静图背后的采样位置与真实渲染一致，特别检查透明叠色、渐变亮斑和纹理最不利处。

## 5. 从颜色值到可读性

sRGB 相对亮度使用线性化通道，两个亮度计算对比 `(Lmax + 0.05)/(Lmin + 0.05)`。只对输入的**明确前景和背景颜色**有效；不能用色板对比替代成图、动态和设备测试。

- 一般文字参考 WCAG 2.2 **4.5:1**，大文本 **3:1**；适用性按平台／文字大小判断。
- 有意义的图标、边界与状态指示器，参考 **3:1** 与相邻底色。
- 颜色无法单独表达成功、失败、不可用和选中，需联合文字／形状等。
- 设计中非重要装饰线不必被错误地用交互控件标准裁决；但不能用“只是装饰”掩盖必要状态信息。

随包工具：

```bash
python <skill-root>/scripts/color_check.py check --palette <palette-json>
python <skill-root>/scripts/color_check.py pair --fg '#283C44' --bg '#F6F2E9' --kind text
```

输入示例（颜色与 kind 按实际用途填写；`text`、`large_text`、`non_text` 分别对应工具内的声明阈值）：

```json
{"readability_pairs": [{"name": "body", "foreground": "#283C44", "background": "#F6F2E9", "kind": "text"}]}
```

首个命令读取项目方案里显式的 `readability_pairs`，**只验证这些对**；未列出的背景、叠色、图片、动效与用户主题依旧是待测。报告反映计算结果，不宣称人群偏好或自动符合平台规范。

## 6. 用失败症状定位变量

| 失败表象 | 优先排查 | 不宜直接做 |
|---|---|---|
| “过素” | 主体／环境是否色相分工，彩度是否失去层次 | 给全部元素加高饱和 |
| “太花” | 焦点数量、同级高彩度面积和邻接 | 全局压成灰白 |
| “太暗” | 阅读区亮度、大面积深色、衣装层次 | 删掉所有深墨结构 |
| “廉价发光” | 同质高光、边缘过度明亮、素材反射逻辑 | 所有物料加厚金线 |
| “分离感” | UI 是否用另一套色温、边缘、材质与图标语言 | 纯靠半透明度抹掉边界 |
| “文字看不清” | 实际背景最不利亮度、字重／尺寸、纹理叠放 | 只让字更亮或减小字号 |
