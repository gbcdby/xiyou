# 参考素材分析与证据纪律

## 来源类别

- 用户原图：保留可定位的来源；归档或固定基准时保存完整字节与稳定编号。按任务授权保存在项目资料中，不写入通用 skill。
- 文章／教程：区分作者论点、提示词、实际配图、局部说明和项目推导；不要把教程口号当作可复现规律。
- 视频／动态：注明实际浏览时间段；静帧不能证明缓动、帧率、骨骼或完整运动。
- 游戏与设计案例：优先一手开发者资料；区分公开图、开发者描述、自己的推断与实际操作验证。不得以选取案例声称代表玩家偏好总体。
- 生成候选：与用户原参考独立编号；明确用户是否选定、局部认可还是已弃用。

## 观察表

| 维度 | 要记录的可见事实 | 可以进行的转译 |
|---|---|---|
| 形与比例 | 大轮廓、主体重心、构造 | 跨角色造型语言 |
| 线面与边缘 | 线宽、提按、硬边／失边 | 焦点和外围的分配 |
| 颜色职责 | 哪个对象占据哪个色面 | 主辅色、环境、文字和强调分工 |
| 光与空间 | 主次层级、遮挡、前中远 | 人景一体的空间组织 |
| 材质与细节 | 布、纱、玉、木、石的不同画法 | 精工节点与安静面比例 |
| 情绪与气韵 | 节奏、留白、动作趋势 | 叙事基调与动态倾向 |
| 界面可读性 | 文字与底色、图标辨识度 | 跨页面的视觉一致性原则 |

每条重要结论应能追溯到相关来源编号或链接。注明反例与适用边界：有些参考只适合作为空间或配色来源，不应整套继承人物身份与装饰密度。

## 证据状态

`imported`：已收文件；`viewed`：确实查看；`inferred`：从图推导；`adopted`：用户或当前项目采纳；`validated`：实际产物或研究已验证。五者不能互换。
