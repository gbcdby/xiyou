# 风格规范与文件验收

## 内容核对

- 引用图片是否真的存在、哈希是否一致、原编号是否稳定；图板不能替代原图。
- 每条重要规则能否找到来源 ID 或用户明确决定；观察、推断与验证不混淆。
- 当前总纲、颜色、人物、环境、UI 视觉与简报是否彼此冲突；用户明确弃用方向是否仍混入正向提示词。
- 大方向请求中是否误带入页面级状态、导航字样、交互位置、经济数值或槽位数据。

## 成图评价（有图才进行）

1. **整体缩略**：第一个视觉焦点、空间层次和配色关系是否成立？
2. **标准阅读**：人物、景物、字体、图标与环境有同一设计语言吗？
3. **局部放大**：脸手、衣缘、材质连接、关键线条与符号的工艺是否清楚？
4. **内容可读性**：文字是否在稳定、对比足够的区域？复杂景物是否避开主要信息？
5. **一致性**：不同人物和季节是否共用画法、材质与符号逻辑，而不被统一滤镜抹去差异？
6. **情绪辨识**：项目指定的“清冷／温暖／治愈／仙”等情绪有哪些具体画面证据，而非形容词？

脚本验收只证明结构、引用与文件完整性，不能冒充视觉、交互或设备验收。

## 可重复验收

[风格与 UI/UX 迭代实验室](evaluation-lab.md)规定素材与产物的检查尺度、对照变量和验证阶段。色值级可运行 `scripts/color_check.py`，仅验证配对纯色，不对美术风格作自动评分。

## 页面与交互验收

本文件检查整体风格。具体界面任务另用 [界面验收清单](interface-validation.md)，覆盖状态、导航、平台输入与实际运行；不把页面合同中的合理细节误判为整体方向污染。
