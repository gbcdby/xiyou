# 视觉系统与 UX 的大方向

这里只记录跨项目可迁移原则；不定义任何特定页面或业务流程。

1. **插画与信息各司其职**：场景能提供情绪，文字、数值、状态和入口有稳定的阅读承托。可让它们使用同一色温、笔触与材质，而非粘贴互不相干的巨大卡片。
2. **先留阅读区域再画背景**：把低纹理、亮度相对稳定且适合前景的区域画进构图中，让自然肌理在外围呼应；不要把复杂枝叶、石纹和强光压在正文上。
3. **靠关系组织层级**：对齐、分组、间距、重复的符号语法比堆叠装饰框更稳定。图标语义不能被过度抽象或画法遮盖。
4. **动作状态清楚**：可点击、不可点击、选中、处理中、成功、失败要有可靠区分；不要只靠颜色而不提供文字／形状信息。
5. **反馈准确**：操作反馈应对应实际变化，未知结果不能表现为成功。复杂性越高，越需要清晰预期、回退与可恢复性。
6. **阅读与触控分开核对**：视觉尺寸不等于命中区；注意字级、背景对比、单手遮挡、触控间隔、辅助操作和减少动态效果。
7. **动态有节制**：舒展的环境运动不应令文字漂移；需要明显反馈时把动势集中在局部，并尊重减少动效偏好。
8. **风格一致，不等于处处一样**：同一设计语言可以服务不同内容密度与情绪强度。让共同的字体原则、图标结构、材料及状态语法跨资产稳定。

参考案例启发来自公开游戏设计文章与指导原则，属方法归纳，不是对任一具体游戏 UI 或玩家总体喜好的认证。新项目须结合其输入与真实任务验证。
