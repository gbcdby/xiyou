| 层次 | 状态 | 证据位置 / 未执行原因 |
|---|---|---|
| 模型检查 | PASS_WITHIN_SCOPE / COUNTEREXAMPLE / INCONCLUSIVE / TOOL_ERROR / NOT_RUN | 原始 result.json、日志、配置 |
