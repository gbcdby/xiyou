# 决定与落实记录

复用项目既有 Issue、契约或记录；只填与本次有关的字段，不要求新建文件。

- **决定与出处**：人的实际指令或可核验授权引用；讨论中的选项单列，不当作决定。
- **类型与对象**：设计接受 / 体验认可 / 合并授权 / 发布授权 / 风险接受 / 目标调整 / 暂停 / 取消 / 恢复；work_id、对象真实修订、相关环境。
- **变化与范围**：旧决定 → 新决定；适用任务、动作、条件，以及不受影响且可以继续的工作。
- **影响**：契约、依赖、负责人、预算、停点和需重新评估的证据；保留旧记录链接。
- **落实**：记录是否写入、通知是否送达、负责人是否接收、实际变化是否核实；每项附状态与证据，未知明确写出。
- **停止状态（涉及才填）**：STOPPED_AT_SAFE_POINT / STOP_PENDING / CANNOT_CONFIRM；最后安全点、仍在途的操作、已完成的外部效果。
- **后续**：原负责人、下一动作、继续条件，以及重新审视本决定的触发条件。

人的接受、操作授权、运行检查和交付状态分别记录。收到消息不代表动作已经完成；没有实证的状态保持待确认。
