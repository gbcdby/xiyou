# 页面验收检查目录

按改动及关联影响选用，不是每次全跑的清单。单处改动只记录受影响属性和关联回归；复杂任务再逐元素展开。采用独立机器计划时，评估 `layout/background/color/border/shape/typography/icon/artwork` 八类属性，适用项写具体目标，不适用项写理由；状态、交互、适配和动效按实际影响补充，不建立属性与设备的笛卡尔积。

依据、观察、推断、接受决定和实测分别记录。脚本只能检查文件、声明与覆盖，不能证明执行者已阅图、截图来自运行环境或用户接受了偏差。

## 目录

| 章节 | 需要时核对 |
|---|---|
| 1–2 | 依据、范围、环境与真实取证 |
| 3–11 | 整体构图、八类视觉属性与公共组件 |
| 12–14 | 状态、操作、适配与可访问性 |
| 15–16 | 连续动效、生命周期与性能 |
| 17–18 | 回归、证据与交付 |

## 1. 依据与范围

- 页面、区域、元素、组件、状态和本次变更／关联影响明确。
- 确认原图与后续修订可追溯；采用区域、组合关系和已排除方案明确。
- 页面基准、画风参考、功能示意、上一版运行图各自职责明确。
- 公共规范、页面合同、组件、token的冲突有处理依据；已确认目标与实现现状分开。
- 精确规格、图片量测和视觉近似分开，单位正确；允许偏差不在修正后偷偷放宽。

## 2. 环境与真实取证

- 目标应用、页面、实际加载产物、代码与素材版本核实；Git哈希不独自证明加载版本。
- 平台、系统、实际宽高比、逻辑视口、截图倍率、安全区、系统栏与字号记录。
- 文案、数据、选择、展开与滚动位置一致；字体、图片、异步内容就绪。
- 排除上一页、白帧、旧图和过渡帧；保留原始截图，转换另存且记录原因。
- 模拟器、真机与未覆盖平台分别结论；假数据不冒充服务端集成。

## 3. 整体构图

- 缩略查看主焦点、主要动作、阅读顺序和主要色面。
- 页面分区、主体比例、密度、留白、视觉重心与依据一致。
- 标题、正文、辅助信息和装饰有主次；背景、人物、图标与按钮不争抢注意。
- 美术和UI在材质、线条、边缘、精度分配及光色上协调。
- 实际阅读尺寸检查整体；局部修正后回看全图。

## 4. 几何与空间关系（layout）

- 位置、宽高、比例、相对锚点及固定／最小／最大／伸缩约束正确。
- margin、padding、行列gap、分组间隔与分隔距离正确。
- 边线、中心线、文字基线对齐；实际视觉中心协调。
- 层级、遮挡和父级裁切正确，边缘不意外截断。
- 文字依附插画时跟随正确局部及图片采样变换，不另用屏幕百分比凑位置。

## 5. 背景与承托（background）

- 背景版本、色调、颗粒、纹理密度、方向和透明度正确。
- cover／contain、裁切、平铺、拉伸符合合同；不同视口的重要区域保留。
- 纸面、雾底与透明承托的范围、羽化、浓淡和层次正确。
- 无拼接缝、明显重复、色带、露底、意外整条底板。
- 背景亮斑、枝叶和高频纹理不穿过主要文字；动态最不利处仍可读。

## 6. 色彩与光影（color）

- 语义token、状态色、品质色与强调职责正确；例外有来源。
- 检查真实背景上的最终叠色，不只比较HEX或纯色色对。
- 渐变方向、色标、范围和透明端正确。
- 阴影、光晕、模糊的方向、偏移、范围和强度正确，无重复叠加。
- 文字、必要符号和边界在最不利背景可辨；装饰不误套功能对比标准。

## 7. 边框与轮廓（border / shape）

- 边框有无、所在边、粗细、颜色、透明度、虚实、内外描边正确。
- 圆角半径、分角差异、内外轮廓衔接及描边内缩正确。
- 几何或装饰轮廓、端部形态与采用设计一致。
- 填色、纹理、裁切和边框之间无缝隙；无断线、异常粗细、毛边或锯齿。
- 内容增长、缩放和不同倍率下形状不变形；规则以平台单位核对。

## 8. 文字（typography）

- 实际字体家族、文件、字重、字形、字号和颜色正确，无意外合成粗体。
- 中英数字、标点和特殊字符无意外回退、缺字、方框；字体文件有字不等于运行时使用它。
- 行高、字距、段距、缩进、基线、文本对齐正确。
- 标题／正文／辅助字／关键读数层级正确，文字与图标／单位间距正确。
- 换行、行数、省略、截断符合合同，首尾字与上下笔画不被裁切。
- 数字、符号、小数、单位和文案正确；字号放大按合同重排，不盲目缩字。

## 9. 图标（icon）

- 语义、素材版本、状态变体正确，无未经采用的emoji、通用替代或错误兜底。
- 同族视角、线宽、转折、抽象程度、填色与材质协调。
- 主体体量、内部留白、视觉中心、朝向、旋转与镜像正确。
- 图标与文字的比例和间距正确；实际显示尺寸仍可识别。
- 功能、状态和装饰不混淆；图标有透明边时同时查素材质量。

## 10. 插画与素材（artwork）

- 身份、姿态、数量、朝向、特征、比例、裁切、透视及人景关系正确。
- 实际底色上无白边、黑边、残底、杂点或不透明矩形。
- 浅色主体、细线、发丝、缝隙和半透明光晕无误删。
- 压缩／缩放／量化无明显色块、断层、糊化或细节损失。
- atlas区域无越界、错切、邻片污染和边缘采样问题。
- 新增或加工素材逐张核；尺寸、格式、体积、版本及必要署名符合合同；按项目素材要求检查母版相关局部。

## 11. 公共组件与控件

- 组件／变体／适用范围正确；最终样式未被页面覆盖成另一套视觉。
- 按钮、页签、输入、标签、卡片内部排版与真实内容适配。
- 选中条、开关、滑块、进度条的位置、方向和比例正确。
- 徽标、角标、品质框和数量不遮盖主体／文字。
- 同类控件一致、不同语义可区分；复用代码不等于实际视觉通过。

## 12. 状态与内容边界（可用 attributes 扩展为 states）

- 默认、选中、未选中、按下、禁用、锁定等适用状态分别检查变化属性。
- 加载、刷新、空态、失败、重试、成功和未知结果诚实表达。
- 长文、多行、大数字、零值、缺字段的层级与布局正确。
- 列表0／1／多项、新增／删除、展开／收起与资源晚到后布局正确。
- 覆盖首屏、滚动中段和末尾，不以首屏代替完整页面。
- 图片／字体失败的降级及恢复正常；完成演出不冒充业务成功。

## 13. 操作与浮层（interaction）

- 可点击外观与行为一致；实际命中区及相邻热区正确，装饰不挡触摸。
- 点按、拖动、滑动、长按和滚动无冲突。
- 弹窗、抽屉、提示、键盘、底部固定区的层级和遮挡正确。
- 遮罩、背景点击、关闭、返回、阻断与处理中退出符合合同。
- 重复操作／重试不误导；返回恢复选择、滚动、展开及输入。
- 全局反馈不被遮挡或重复；表单标签、输入类型、校验及键盘避让正确。

## 14. 适配与可访问性（accessibility）

- 按支持平台和实际宽高比选代表；高度适配涉及普通、短、高视口时分别覆盖，不用同宽高比的大尺寸代替高屏。
- 安全区、刘海、系统栏、手势区、键盘和固定区不遮挡内容，末尾可达。
- 支持字号按计划验证；改字号后重新进入／重建捕获稳定帧。
- 仅检查支持的主题、语言、方向与输入；不借清单新增暗色、横屏、平板。
- 辅助标签、角色、状态、顺序和焦点正确；装饰不抢阅读焦点。
- 状态不只依赖颜色；文字、符号、边界与焦点按采用要求可辨；适用键盘／控制器路径可用。

## 15. 连续动效（motion）

- 触发、初态、终态、时长、缓动和目的正确。
- 坐标系、旋转轴、投影、朝向、缩放、跟随及锚点正确。
- 容器、文字、图标、光效协调，中间帧无闪烁、跳变、形变、断尾、越界或错误层级。
- 离场及数量变化期间父级不提前收缩；循环接缝、结束回落正确。
- 中断、反向、重触发、返回、恢复、减弱动态按合同接续；文字保持可读。
- 按motion-validation分支保存连续证据，不用终态截图证明过程。

## 16. 生命周期与性能（lifecycle / performance）

- 冷启动和首次进入无错默认、白闪或旧内容闪现；资源就绪前后不跳位。
- 切换、重挂载、前后台恢复正确，常驻内容／动效组件不意外消失或重播。
- 滚动、弹层、切换、并发动效与长列表无明显卡顿、空白或旧项复用。
- 素材解码、内存、包体、帧率／功耗符合已采用预算；无测量保留待验证。
- 模拟器变帧率录屏、机器高负载和主观流畅感不冒充产品性能测量。

## 17. 一致性与回归（consistency）

- 同用途字体、边框、形状、图标和状态语义一致，新旧素材不混成两套语言。
- 局部已采纳例外保留范围，不错误推广到全项目。
- 公共组件、字体、token和素材修改复验相关消费者。
- 单属性修改复验连带关系，例如字体→换行→高度→邻近区。
- 原确认图判断还原、上一版判断回归；正式接入与独立原型分别验证。

## 18. 证据与交付（evidence）

- 缩略／实际阅读／相关局部已阅；完整全图先保留，局部不能隐藏全图偏差。
- 全图并排／叠图与必要局部对照实际打开；差异比例不是还原率。
- 所选检查项有目标、依据、观察、证据及结论；完整计划模式逐元素／属性覆盖，不用一行“正常显示”替代。
- 通过／失败／待验证／不适用明确区分；不适用说明理由，例外有接受来源。
- 受影响项修正后复验；旧轮次保留，最终证据关联交付版本。
- 未覆盖设备／状态／屏外区域不包含在通过结论；静态视觉、交互、连续动效、性能和代码测试分别报告。
- 最终向用户直接展示一张“确认图左、实现右”的合图及必要局部，标明页面／状态／版本；不只给文件路径。
- 预览可等比缩小／补白，明确为展示用途，不能拿独立缩放预览计算对齐或还原率；原始图、严格对照图保留。
- 新设计决定交回现有规范负责人；旧决定明确替代，未测不得写成通过。
