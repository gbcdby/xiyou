# 连续动效与视觉审查交接

用于旋转、拖动、镜头、缩放、跟随、粒子／尾迹、展开收起或状态形变；静态改字不必执行。先在目标平台验证一个能暴露主要问题的最小片段，再整合页面。截图验证形态，连续录屏验证过程，两者不能互代。

## 最小运动合同

在现有页面／原型记录说明：

- 对象处于屏幕、地图／世界还是局部平面坐标；旋转轴、投影顺序、朝向和跟随对象。注明哪些内容保持朝向、哪些随父级变换，避免旋转后透视翻转。
- 缩放输入、上下限及共同缩放对象；前景／背景的视差和稳定锚点。资源、头像、标签与特效的层级及允许遮挡范围。
- 默认／运动／停止状态的可见内容；过渡触发、时长、光／形态衔接，以及中途反向时从哪里继续。精确值来自本页决定，不设通用毫秒值。
- 资源加载、重新挂载、缩放与动画进度是否连续；帧率／功耗预算及本次实际可测环境。无测量则保留待验证。

## 路径适用性

按真实状态列出本轮适用路径，标记实际验证／待验证／不适用及理由，不要求产品新增状态：

| 路径 | 核对重点 |
|---|---|
| 出现、退出和内容数量变化（如 2→1、2→0） | 离场元素尚存期间，父级尺寸、锚点与相邻常驻区不提前收缩或重排 |
| 正向、反向和过渡中反复操作 | 从当前进度接续；文字、图标、光效和容器的速度及终点协调 |
| 冷启动、资源晚到、卸载重挂载 | 首个可见帧位置稳定，不闪出错误默认状态 |
| 后台／前台、离开／返回 | 恢复当前状态，按合同决定续播或落终态，不意外重播入场 |
| 系统减弱动态的进入与退出 | 静态／简化态仍表达当前状态；恢复普通模式后的下一次操作正常过渡 |

没有确认图时引用已确认的行为、锚点和时序作为依据，动态结论不冒充按图还原通过。

## 捕获与判断

绑定代码／素材版本、设备、环境负载与复现操作。只捕获适用路径：持续运动、转向、缩放极值及中间值、起停、中途反向；检查闪烁、突然显隐、断尾、形变、层级和文字可读性。缩放中和过渡中也要观察，不能只拍终态。先用短录屏和关键帧拼图定位，再按最终版本复验受影响路径；不把终态单元测试当作中间帧连续性证据。

环境持续超时先按项目现有设备／运行环境方法诊断，不靠反复换设备或无限重跑。高负载环境只能给出该条件下的视觉观察，不能据此判定产品性能；设备恢复后补测所需指标。

## 审查交接

有原参考时同时提供已确认原参考、当前真实截图／录屏及可用的上一版；无图分支交接已确认行为合同，分别注明版本与采用范围。原参考判断还原，上一版发现回归；缺少上一版则明确缺口，不能把它当新基准。先列可观察差异，再按合同判断允许偏差、修复或待验证，不以测试数量或“Spec零问题”替代视觉判断。

静态对照继续沿用本技能的同状态、等比映射、并排／叠图规则，不另设还原率。动态结论与静态视觉、交互、性能结论分别报告。

短片录制将开始、操作序列和停止放进同一个有界工具编排，时长留出设备调用余量；停止失败时不把旧录像算作本轮证据。优先压缩关键帧拼图，按需看原帧；模拟器变帧率录像不作为 FPS 性能测量。
