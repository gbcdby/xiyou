## 离线恢复核对

在隔离的干净基线checkout中，将补丁置于可读位置，先运行`git apply --check --whitespace=nowarn text-changes.patch`，再运行`git apply --whitespace=nowarn text-changes.patch`，逐项与清单核对。`--whitespace=nowarn`只保留原有EOF空行，不改源字节。恢复后的文字投影缺少图片，不能运行素材验收或充当完整源tree。
